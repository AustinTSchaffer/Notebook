## Direct Manipulation

- VR
	- Possible to design in 3D, instead of 2D
	- struggles with feedback issues

> **Reflection**
> 
> One example is a typical SQL based CRUD application. To find a record to update, you need to write a pretty verbose SQL query in order to find the record you want to change. Then you need to write a fairly verbose update statement to select exactly the record you want to update, making sure you scope the update to just one single record, then run it and hope the output says "one record updated".
>
> To address this, some SQL editors, notably DataGrip, allow you to edit records directly in the results view. You sometimes still need to write fairly complicated SQL queries to select data, but the interface lets you make changes to individual data points by interacting with the data itself.

## Invisible Interfaces

- invisibility by learning
- invisibility by design
- "When you do things right, people won't be sure that you've done anything at all."
- 5 tips
	- use affordances
		- places where the visual design indicates how things should be used
	- know your user(s)
	- differentiate your user
		- design for novices
		- design for experts
		- these should be the same interface
	- let your interface teach
		- menu selection should also show hotkeys
	- talk to your user
		- interviews
		- feedback forums
