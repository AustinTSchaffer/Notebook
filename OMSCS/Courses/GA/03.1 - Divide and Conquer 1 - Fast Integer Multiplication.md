## Multiplying Integers
- Given $n$-bit integers
- Goal: compute $z=xy$
- Real Goal: compute $z$ faster than $O(n^2)$

## Gauss's Idea
Setting
- Multiplication is expensive
- adding/subtracting is cheap

- 2 complex numbers
	- $a+bi$
	- $c+di$
- $(a+bi)(c+di) = ac-bd+(bc+ad)i$
- Need 4 real-number multiplications: $ac, bd, bc, ad$
- Can we reduce the number of multiplications?
- We will compute $(bc+ad)$ with only one multiplication.
- $(a+b)(c+d)=ac-bd+(bc+ad)$
- $(bc+ad)=(a+b)(c+d)-ac-bd$
- Putting it together: $(a+bi)(c+di) = ac-bd+((a+b)(c+d)-ac-bd)i$
- Only need to compute these products: $ac, bd, (a+b)(c+d)$

## Naive Approach
**Input:**
- 2 $n$-bit integers $x$ and $y$.
- Assume $n$ is a power of 2.

**Goal:**
- compute $z=xy$, with running time in terms of $n$

**D&C idea:**
break input into 2 halves. Partition both $x$ and $y$ into 2 halves.
- $x=x_L | x_R=(2^{\frac{n}{2}})x_L+x_R$
- $y=y_L | y_R=(2^{\frac{n}{2}})y_L+y_R$
- Each substring of each number is $n/2$ bits long.

**Example:**
$x=182=(1011 \space 0110)_2$
- $x_L=(1011)_2=11$
- $x_R=(0110)_2=6$

**Recursive Idea**
$$z=xy=\left(\left(2^{\frac{n}{2}}\right)x_L+x_R\right)\left(\left(2^{\frac{n}{2}}\right)y_L+y_R\right)$$
$$=2^nx_Ly_L+2^{n/2}(x_Ly_R+x_Ry_R)+x_Ry_R$$

We can now also recursively compute the sub-products (), using $n/4$ bits from the original numbers.
- $x_Ly_L$
- $x_Ly_R$
- $x_Ry_L$
- $x_Ry_R$

**Naive Pseudocode**
$EasyMultiply(x,y):$
	input: $n$-bit integers $x$ and $y$, $n=2^k$
	output: $z=xy$
	$x_L=x_{((n/2)+1)..n}$
	$x_R=x_{1..(n/2)}$
	$y_L=y_{((n/2)+1)..n}$
	$y_R=y_{1..(n/2)}$
	$A=EasyMultiply(x_L,y_L)$
	$B=EasyMultiply(x_R,y_R)$
	$C=EasyMultiply(x_L,y_R)$
	$D=EasyMultiply(x_R,y_L)$
	$z=A2^n + 2^{n/2}(C+D)+B$
	$\text{return(z)}$

- Breaking up $x$ and $y$ into their respective halves takes $O(n)$ time.
- The recursive calls take $4T(n/2)$
- Multiplying by $2^n$ can be sped up using a bit-shift operation.
- $T(n)=$ the worst-case running time of EasyMultiply on input of size $n$
- $T(n)=4T(n/2)+O(n)=O(n^2)$ ([[03.3 - Divide and Conquer 3 - Solving Recurrences#General Recurrence]])
