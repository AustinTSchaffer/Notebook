# 02.3 - Dynamic Programming 3 - Shortest Paths

- Directed $\overrightarrow{G}=(V,E)$ with edge weights $\omega(e)$. For the rest of this document $G=\overrightarrow{G}$.
- Fix $s \in V$
- For $z \in V$, $dist(z)=$ length of shortest path from $s$ to $z$

![[Pasted image 20260217193049.png]]

- $dist(s)=0$
- $dist(b)=5$
- $dist(a)=8$
- $dist(d)=12$
- $dist(e)=6$
- $dist(f)=11$

## Classic Algorithm: Dijkstra's Algorithm.
- Given $G$ and $s \in V$
- Finds $dist(z)$ for all $z \in V$
- Performs a BFS. Uses a min-heap data structure.
- $O((n+m)log(n))$ where $n=|V|$ and $m=|E|$
- Requires that $\forall_{e \in E} \space w(e)>0$. If edge weights are allowed to be negative, it's not guaranteed to find the shortest path.

## Negative Weight Cycles
First question: Is this problem well-defined?

![[Pasted image 20260217193612.png]]

What is $dist(d)$? The $b \rightarrow a \rightarrow e \rightarrow b$ cycle has a cost of -1. Taking this cycle an infinite number of times is the winning strategy. The problem becomes well-defined if we're only allowed to visit a vertex once, because it eliminates cycle-hacking.

**More general problem:**
Given $G$ with $\omega(e)$ and $s \in V$, find a negative weight cycle which is reachable from $s$. Otherwise, find $dist(z)$ for all $z \in V$.

## DP: Single-Source
Given $G$ with edge weights, and $s \in V$. Assume for now that there are no negative weight cycles.

- Shortest path from s to z visits every vertex $\le 1$.
- $P$ is the shortest path from $s$ to $z$
- $|P| \le n-1$ edges

### DP Idea 1
- use $i=0 \rightarrow n-1$ edges on the paths
- Assume no negative weight cycles

### Subproblem Definition
For $0 \le i \le n-1$ and $z \in V$.
	- let $D(i,z)=$ length of shortest path from $s$ to $z$ using $\le i$ edges.

### Recurrence
- Base Cases
	- $D(0, s)=0$
	- for all $z \in V$ where $z \ne s$, $D(0,z)=\infty$
- for $i \ge 1$
	- $D(i,z)=\min\Big\{ D(i-1,z), min_y \big\{ D(i-1,y) + \omega(y,z) \big\} \Big\}$

## Finding a Negative Weight Cycle
![[Pasted image 20260217195551.png]]


| i   | s   | a     | b     | c     | d      | e   |
| --- | --- | ----- | ----- | ----- | ------ | --- |
| 0   | 0   | inf   | inf   | inf   | inf    | inf |
| 1   | 0   | 5     | inf   | inf   | inf    | inf |
| 2   | 0   | 5     | 8     | inf   | inf    | inf |
| 3   | 0   | 5     | 8     | 2     | 12     | inf |
| 4   | 0   | **4** | 8     | 2     | 12     | 8   |
| 5   | 0   | 4     | **7** | 2     | 12     | 8   |
| 6   | 0   | 4     | 7     | **1** | **11** | 8   |
When there's a negative weight cycle, every row will be different from each other. $a$ will decrease, $b$ will decrease, $c$ will decrease, $a$ will decrease, etc.

If there's no negative weight cycle, we can stop at $n-1$. If there exists some $z \in V$ such that $D(n,z)$ is strictly smaller than $D(n-1, z)$, there must be some negative weight cycle in the graph.

$$\exists_{z \in V} : D(n,z) < D(n-1, z)$$

We can detect that cycle by backtracking through the table to see all of the vertexes that it affects.

## All Pairs Shortest Path
- **Given** $G=(V,E)$ with edge weights $\omega(e)$. 
- For $y,z \in V$, let $dist(y,z)=$ length of shortest path $y \rightarrow z$.
- **Goal:** find $dist(y,z)$ for all $y,z \in V$

**Easy approach**, run Bellman-Ford for all $s \in V$. This is $O(n^2 m)$. $m$ can range from $n-1$ to $n^2$, so this algorithm is somewhere between $O(n^3)$ and $O(n^4)$. There also exists Floyd-Warshall, which is an $O(n^3)$ algorithm.

### Algorithm Idea
- Basic idea of the bellman-ford algorithm
	- condition on the number of edges
- input is the graph
- Can we prefix on the vertices of the graph?

### New Idea
- let $V=\{1, 2, ..., n\}$
- now we can look at a prefix of the vertices.
- 3 parameters
	- $0 \le i \le n$ is the prefix size of $V$ for the current "pass"
	- $1 \le s \le n$ the index of a start vertex
	- $1 \le t \le n$ the index of an end vertex
- $D(i,s,t)=$ length of the shortest path $s \rightarrow t$ using a subset of $\{1,...,i\}$ as intermediate vertices.

### Recurrence
Base Case

$$
\begin{equation}
  D(0,s,t) =
    \begin{cases}
      w(s,t) & \text{if } \overrightarrow{s,t} \in E \\
      \infty & \text{otherwise}
    \end{cases}       
\end{equation}
$$

For $i \ge 1$, look at shortest path $P$ $s \rightarrow t$ using $\{1, ..., i\}$.

If $i$ is not on the shortest path $P$ from $s$ to $t$, we can simply recurse on $D(i-1,s,t)$, and take the previous answer.

If $i$ **IS** on the shortest path $P$ from $s$ to $t$, then we need to think about the actual route from $s$ to $t$.
- $V'_a$ is some subset of vertices $\{1,...,i-1\}$
- $V'_b$ is some subset of vertices $\{1,...,i-1\}$
- $V'_a$ and $V'_b$ are disjoint and share no common vertexes. Either or both may also be null sets.
- The path from $s$ to $t$ looks like: $s \rightarrow V'_a \rightarrow i \rightarrow V'_b \rightarrow t$
- The length of $P$ can therefore be expressed in terms of reaching $i$ from $s$, and reaching $t$ from $i$: $D(i-1,s,i)+D(i-1,i,t)$

$$D(i,s,t) = min \Big\{ D(i-1,s,t), D(i-1,s,i)+D(i-1,i,t) \Big\}:0 \le i \le n
$$

### Negative Weight Cycles
This algorithm assumes there's no negative weight cycles. How do we detect a negative weight cycle?

The output of Floyd-Warshall is a 2D table, showing the min distance between pairs of vertices. The table also shows the minimum distance between any vertex $y \in V$ and itself along the diagonal. If any vertexes are part of a negative weight cycle, they will have a negative $P$ in this resulting table.

## Comparison
- Bellman-Ford
	- Finds the shortest paths from some start node $s$ to all other nodes reachable from $s$
	- Finds negative weight cycles within the set of nodes that are reachable from $s$
	- $O(|V||E|)$
	- Can be extended to find $\hat{P}$ for all pairs of nodes in $O(|V|^2|E|)$ time.
- Floyd-Warshall
	- Finds the shortest paths between all pairs of nodes.
	- Finds negative weight cycles even when the graph is not reachable from some nodes.
	- Runs in $O(|V|^3)$ time.
