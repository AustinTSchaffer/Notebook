# 04.3 - Graphs - Minimum Spanning Tree (MST)

## Greedy Approach
- Take locally optimal move.
- When does that lead to global optimum?
- Doesn't work for knapsack. [[02.1 - Dynamic Programming 2 - Knapsack]]
- Does work for MST
	- Kruskal's algorithm
	- The "cut property"
	- Prim's Algorithm

## MST Problem
**Given**
- Undirected $G=(V,E)$
- Weights $w(e)$ for $e \in E$

**Goal**
- find minimal size, connected subgraph
- This is the spanning tree, of minimum weight
- for $T \subset E$ find $T$ which minimizes $\sum_{e \in T} w(e)$, while still creating a spanning tree.

## Tree Properties
- A tree is a connected, acyclic graph.
- NOT a DAG, because it's not directed.
- A tree on $n$ vertices has $n-1$ edges.
- In a tree, there's **exactly** one path between every pair of vertices.
- Any connected $G=(V,E)$ with $|E|=|V|-1$ is a tree. This is the important property that we're going to use later.

## Kruskal's Algorithm
![[Pasted image 20260302213242.png]]

### Runtime Analysis
- Sort E: $O(m \space log \space n)$
- For $e=(v,w) \in E$...
	- Let $c(v)=$ a component containing $v$ in $(V,X)$
	- Let $c(w)=$ a component containing $w$ in $(V,X)$
	- If $c(v) \ne c(w)$, then add $e$ to $X$
	- **Use a Union-Find data structure**
		- $O(log\space n)$ lookup time.
		- Merging $c(v)$ with $c(w)$ also takes $O(log \space n)$ time.
		- Uses "Rooted Directed Trees"
	- $m$ total operations, where each operation takes $O(log \space n)$ time.
	- $O(m \space log \space n)$
- **Total:** $O(m \space log \space n)$

### Correctness
Why does the greedy algorithm work?

**Assume by induction**
- $X$ is correct so far.
- $X \subset T$, where $T$ is a MST
- add $e=(v,w)$ to $X$
- **Claim:** $(X \cup e) \subset T'$ where $T'$ is a MST

- Presume $S$ is the set of vertices $u$ where $c(u) = c(v)$.
- $\overline{S}$ is the set of vertices which is the complement of $S$.
- $S$ is a maximal set, so there's no edges between $S$ and $\overline{S}$. $X$ doesn't cross $S \leftrightarrow \overline{S}$
- $e=(v,w)$ does cross $S \leftrightarrow \overline{S}$
- Any minimum weight edge $e$ which crosses between $S$ and $\overline{S}$ must be part of a MST. Therefore, adding $e$ to $X$ must be some subset of an MST.

$(X \cup e) \subset T'$ is known as the "cut property"

## Cuts
For undirected $G=(V,E)$, we have some partitioning of $V$ into $S$ and $\overline{S}$. $V=S \cup \overline{S}$.

$cut(S, \overline{S})=\{ (v,w) \in E : v \in S, w \in \overline{S} \}$
- cuts are edges crossing $S \leftrightarrow \overline{S}$
- The 5 edges below with red squiggles are the "cuts"

![[Pasted image 20260302214837.png]]

### The Cut Property
**Lemma:** For undirected graph $G=(V,E)$
- take $X \subset E$ where $X \subset T$ for MST $T$
- take $S \subset V$ where no edge of $X$ is in the $cut(S, \overline{S})$
- look at all edges of G in $cut(S, \overline{S})$
- let $e^*$ be any minimum weight edge in $cut(S, \overline{S})$
- We can add $e^*$ to $X$ and still be on our way to building an MST
- $(X \cup e^*) \subset T'$ where $T'$ is an MST

![[Pasted image 20260302215532.png]]

> Any edge which is minimum weight across a cut is part of an MST.

If you're given an MST $T$ which does not contain some edge $e^*$, then we can construct a new MST $T'$ whose total weight is AT MOST $T$.

### Proof Outline
- Fix $G$
- Fix $X$
- $X \subset T$ where $T$ is MST
- no edge of $X$ crosses $S \leftrightarrow \overline{S}$
- $w(e^*) = min \space \{ w(e) : e \in cut(S, \overline{S}) \}$
- if $e^* \in T$ then $T' = T$ 
- if $e^* \notin T$
	- Look at $T \cup e^*$
	- this creates a cycle $C$
	- we need to drop an edge from $C$
	- the edge we drop needs to have $w(e') \ge e^*$
	- we know that $e^*$ was the minimum weight edge across $cut(S, \overline{S})$
	- take any $e' : e' \in T, e' \ne e^*, e' \in cut(S, \overline{S})$
	- We know that $e'$ exists, because there must have already been at least one edge crossing $cut(S, \overline{S})$ in order to form a cycle.
	- $T'=(T \cup e^*) - e'$
- Now we have $T'$

### T' is a Tree
When we do $T'=(T \cup e^*) - e'$, how do we prove that $T'$ is a tree?
- $T'$ must be connected and must have $n-1$ edges.
- For $y,z \in V$
	- Let $P$ be path $y \rightarrow z$ in $T$, containing $e'=(c,d)$
	- Let $C$ be cycle in $T \cup e^*$
	- Let $C$ contain edge $e'=(c,d)$
	- Let $P'=C-e'$. $P'$ is now a path $c \rightarrow d$ in $T'$
	- To go $y \rightarrow z$ in $T'$, use $P$, replace removed edge $e'$ by entire path $P'$
	- This results in a walk from $y$ to $z$. We can truncate the walk to make a path.

### T' is an MST
- We know that $w(T)$ is minimum.
- We know that $w(e^*) \le w(e')$
- $w(T')=w(T)+w(e^*)-w(e') \le w(T)$
- $w(e^*)-w(e') \le 0$
- $w(T') \le w(T)$

**Key Idea 1:** We can take tree T and add an edge into that tree, which creates a cycle. Removing **any** edge of that cycle creates a new tree.

**Key Idea 2:** The minimum weight edge across the cut of a graph is part of an MST.
