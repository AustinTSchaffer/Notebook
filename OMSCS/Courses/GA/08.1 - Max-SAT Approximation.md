# 08.1 - Max-SAT Approximation
SAT Problem:
- **Input:** Boolean formula $f$ in CNF with $n$ variables and $m$ clauses
- **Output:** Assignment satisfying $f$, NO if $f$ has no satisfying assignment
- NP-Complete

Max-SAT Problem:
- Optimization version of SAT problem
- **Input:** Boolean formula $f$ in CNF with $n$ variables and $m$ clauses
- **Output:** Assignment maximizing number of satisfied clauses
- NP-Hard (no way to efficiently verify)

SAT can be reduced to Max-SAT. We can approximate Max-SAT with LP.

## Approx Max-SAT
For a formula $f$ with $m$ clauses, let $m^*(f)$ denote the max number of sat. clauses. We will simplify our notation. and stick with $m^*$.

- Clearly, $m^* \le m$. If $m^*=m$, then $f$ is satisfiable.
- Construct algorithm A on input $f$ with outputs $l$ where $l \ge m^*/2$
- This is a $\frac{1}{2}$-approx algorithm

## Outline
1. Simple Alg: $\frac{1}{2}$-approx alg for Max-SAT
2. LP-based: $(1-\frac{1}{e})$-approx alg
3. Best of 2: $\frac{3}{4}$-approx alg

## Simple Scheme
- Consider $f$ with variables $x_1,...,x_n$ and clauses $C_1,...,C_m$
- Random assignment
	- Set $x_i=T$ with prob $1/2$
	- Set $x_i=F$ with prob $1/2$
	- Do this for all $n$ variables
- How do we measure performance?
- Let $W=$ number of satisfied clauses.
	- $W$ is a random variable.
	- What's $E[W]$?
	- This is the standard definition of the expectation of a random variable.
	- We need to break up this variable into a clause-by-clause variable

$$E[W]=\sum_{l=0}^{m} l \cdot Pr(W=l)$$

## Expectation
- $W=$ the number of satisfied clauses
- Consider $C_j$
	- Let $W_j \in \{1,0\}$.
	- $W_j=1$ if $C_j$ is satisfied.
	- $W_j=0$ otherwise.

$$W=\sum_{j=1}^m W_j$$
$$E[W]=E \left[\sum_{j=1}^m W_j\right]=\sum_{j=1}^m E\left[W_j\right]$$

Now we can focus on each clause in isolation.

$$E\left[W_j\right]=1\cdot Pr(W_j=1)+0\cdot Pr(W_j=0)=Pr(W_j=1)$$

The probability that a given clause is not satisfied is $2^{-k}$, where $k$ is the number of literals in the clause. Therefore, the probability that a given clause is satisfied is $1-2^{-k}$. The probability that a given clause is satisfied **improves** as the size of the clause increases.

$$Pr(W_j=1)=1-2^{-k} \ge \frac{1}{2}$$

We now have a randomized algorithm which is a $\frac{1}{2}$-approx in expectation. We can also formulate a deterministic algorithm by conditional expectation.
- For $i=1\rightarrow n$.
	- Try $x_i=T$ and $x_i=F$
	- The earlier $x_{j=1 \rightarrow (i-1)}$ are fixed.
	- Compute the expected performance of each option, taking a random assignment over the variables $x_{j=(i+1) \rightarrow n}$
	- Take the better of the 2 assignments.

Some final notes.
- Every formula has an assignment which satisfies at least half the clauses.
- If the average is at least $m/2$, there must be at least one setting which achieves the average.

## $Ek$-SAT
- Exact $k$-SAT
- Every clause has size exactly $k$
- What if every clause has size $=3$?
	- $Pr(C_j \text { is satisfied})=\frac{7}{8}$
	- $\frac{7}{8}$-approx for max-$E3$-SAT
	- It's NP-Hard to do better than $\frac{7}{8}$
	- If we find an algorithm which is $0.88$-approx, then we prove that $P=NP$.
- What if size $= k$?
	- $Pr(C_j \text{ is satisfied})=1-2^{-k}$
	- $(1-2^{-k})$-approx for max-$Ek$-SAT
- This algorithm works well when all clauses are large.
- The LP algorithm works better when all clauses are small.

## Integer Linear Programming
- LP Problem
	- $\max \space c^Tx$
	- s.t. $Ax \le b$ and $x \ge 0$
- ILP Problem
	- $\max \space c^Tx$
	- s.t. $Ax \le b$ and $x \ge 0$
	- $x \in Z^n$ (integers)
	- The only feasible points are the "grid" points which exist within the feasible region.
	- We want to find the best "grid point".
- ILP is much harder, because the vertices of the feasible region are possible solutions in LP, but might not be in ILP. 
- ILP is NP-Hard.
- Many NP problems are "easily" reducible to ILP.


## ILP is NP-Hard
- Reduce Max-SAT to ILP
- Take input $f$ for Max-SAT.
- For each $x_i \in f$, add $y_i$ to ILP
- For each $C_j \in f$, add $z_j$ to ILP
- General  Constraints
	- $0 \le y_i \le 1$
	- $0 \le z_j \le 1$
- Now we need constraints to model every clause $C_j$


Consider clause $C_j=(x_5 \vee x_3 \vee x_6)$. If we set all of these variables to false, then $C_j=F$. Therefore, if $y_5=0,y_3=0,y_6=0$, then $z_j=0$. If we set any of these variables to $T/1$, then $z_j=1$. We can't force $z_j$ to be $1$, but we can use the $z$ variables in our optimization function, to coerce their values to 1. We need to add the constraint that if all 3 variables are 0, then $z_j=0$. This is achieved by:

$$y_5+y_3+y_6 \ge z_j$$

Consider clause $C_j=(\overline{x_1} \vee x_3 \vee x_2 \vee \overline{x_5})$. If $y_1=1,y_3=0,y_2=0,y_5=1$ then $z_j=0$. We need to consider the complement of the negative literals when constructing the clause-constraint.

$$(1-y_1)+y_3+y_2+(1-y_5) \ge z_j$$

In general, for every clause $C_j$
- $C_j^+=$ the positive literals in $C_j$
- $C_j^-=$ the negative literals in $C_j$

### Reduction
For CNF $f$, the ILP problem

- Objective: $\max \sum_{j=1}^m z_j$
- Constraints:
	- For all $i=1,...,n:$
		- $0 \le y_i \le 1$
		- $y_i \in Z^n$ (integer)
	- For all $j=1,...,m:$
		- $0 \le z_j \le 1$
		- $\sum_{i \in C_j^+}y_i + \sum_{i \in C_j^-} (1-y_i) \ge z_j$
		- $y_i \in Z^n$ (integer)

This ILP is equivalent to the Max-SAT problem.

### LP Relaxtion
- Consider ILP solution $y^*,z^*$
- What is the value of the objective function? It's simply: $z_1^*+z_2^*+...+z_m^*$
- $m^*$ is the number of satisfied clauses in $f$.
- $m^*=z_1^*+z_2^*+...+z_m^*$
- We can't solve ILPs in poly-time, but we can solve LPs in poly-time.
- Taking off the integer constraints converts this ILP to a "relaxed" LP
- These LP solutions are denoted $\widehat{y^*}, \widehat{z^*}$
- The value of the objective function at this optimal point is $\widehat{z_1^*}+\widehat{z_2^*}+...+\widehat{z_m^*}$
- Any feasible point in the ILP is a feasible point in the LP
- The LP considers more points than the ILP. Therefore, the ILP solution
- $m^*=\left(z_1^*+z_2^*+...+z_m^*\right) \le \left(\widehat{z_1^*}+\widehat{z_2^*}+...+\widehat{z_m^*}\right)$
- This gives us an upper bound on the ILP solution.
- We now need to convert the optimal LP solution to a feasible ILP solution. This solution may not be optimal, but it may be close to optimal.
- Rounding these to integer points $\widehat{y^*}, \widehat{z^*}$ should give us a feasible integer point which is "not that far" from a true optimal solution.

### Rounding the LP Solution
- Optimal LP: $\widehat{y^*}, \widehat{z^*}$
- $\widehat{y^*}, \widehat{z^*}$ might be fractional
- We want integer point ${y}, {z}$ which is close to ${y^*}, {z^*}$.
- Note that $0 \le \widehat{y^*_i} \le 1$
- Set $y_i$ probabilistically
	- $1$ with probability $\widehat{y^*_i}$
	- $0$ with probability $1-\widehat{y^*_i}$
- This is called "Randomized Rounding"
- We don't need to round the $z$'s. Those can be reconstructed from the $y$ values.

### Expectation
- Let $W=$ the number of satisfied clauses
- $W_j$ takes value 1 if $C_j$ is satisfied, and 0 if not.
- $W=\sum_{j=1}^m W_j$

$$E[W]=\sum_{j=1}^m E[W_j]=\sum_{j=1}^m Pr(C_j \space is \space sat.)$$
**Lemma:** $Pr(C_j \space is \space sat.)\ge (1-\frac{1}{e})\widehat{z_j^*}$

$$E[W] \ge \left(1-\frac{1}{e}\right)\sum_{j=1}^m \widehat{z_j^*} \ge \left(1-\frac{1}{e}\right)m^*$$

Therefore, we have $E[W] \ge \left(1-\frac{1}{e}\right)m^*$, meaning $W$ is within $\left(1-\frac{1}{e}\right)$ (~63%) of $m^*$

### Lemma
**Lemma:** $Pr(C_j \space is \space sat.)\ge (1-\frac{1}{e})\widehat{z_j^*}$

- Look at $C_j=(x_1 \vee x_2 \vee ... \vee x_k)$
- LP: $\widehat{y_1^*}+...+\widehat{y_k^*} \ge \widehat{z_j^*}$
- $Pr(C_j \text{ is sat}) = 1 - Pr(C_j \text{ is unsat})$
- $Pr(C_j \text{ is unsat})=\prod_{i=1}^k(1-\widehat{y_i^*})$
- $Pr(C_j \text{ is sat})=1-\prod_{i=1}^k(1-\widehat{y_i^*})$

### Arithmetic Mean and Geometric Mean (AM-GM)
For $w_1,...,w_k \ge 0$

$$AM_W=\frac{1}{k}\sum_{i=1}^k w_i \ge \left(\prod_{i=1}^k w_i\right)^{1/k} = GM_W$$
$$w_i=1-\widehat{y_i^*}$$
$$AM_W=\frac{1}{k}\sum_{i=1}^k \left(1-\widehat{y_i^*}\right)\ge \left(\prod_{i=1}^k \left(1-\widehat{y_i^*}\right)\right)^{1/k} =GM_W$$
$$AM_W=\left(\frac{1}{k}\sum_{i=1}^k \left(1-\widehat{y_i^*}\right)\right)^k \ge \prod_{i=1}^k \left(1-\widehat{y_i^*}\right) =GM_W$$

$$Pr(C_j \text{ is sat})=1-\prod_{i=1}^k\left(1-\widehat{y_i^*}\right)$$
$$Pr(C_j \text{ is sat}) \ge 1-\left(\frac{1}{k}\sum_{i=1}^k \left(1-\widehat{y_i^*}\right)\right)^k$$
$$Pr(C_j \text{ is sat}) \ge 1 - \left( 1 - \frac{1}{k} \sum_{i=1}^k \widehat{y_i^*} \right)^k$$
$$\widehat{y_1^*}+...+\widehat{y_k^*}\ge \widehat{z_j^*}$$
$$Pr(C_j \text{ is sat}) \ge 1 - \left( 1 - \frac{\widehat{z_j^*}}{k} \right)^k$$

If we use Calculus...

$$Pr(C_j \text{ is sat}) \ge \left[ 1-\left(1-\frac{1}{k}\right)^k 
\right]\widehat{z_j^*}$$
If we use some properties of $e$...

$$Pr(C_j \text{ is sat}) \ge \left(1 - \frac{1}{e}\right) \widehat{z_j^*}$$

## Summary
- Take any NP-Hard problem, can likely be reduced to ILP
- Relax the ILP problem it an LP problem
- Solve the LP problem
- Perform a randomized rounding of the LP solution
- This will be a reasonable approximation of the original problem's objective

## Best of 2
- Given $f$
	- Run simple randomized alg, get $m_1$
	- Run LP scheme, get $m_2$
	- Take better of 2.
- $E[\max\{m_1,m_2\}] \ge \frac{3}{4}m^*$
- This is the $\frac{3}{4}$-approx alg.
