# 04.0.1 - Graphs - Black Box Algorithms
For the graphs section of this course, you must use the algorithms presented in the course materials to help solve presented problems. Solutions in this section of the course **must use** one (or a combo) of the black-boxes to solve the presented problem.

## Notes
- **Memorizing this document is *crucial* to the 2nd third of this course.**
- Providing full implementation details of one of these black boxes and adding in a twist or inline tracking will be treated as a modification.
- Many graph algorithms exist beyond what is covered in this course. Only the ones explicitly mentioned here may be used. The use of extra-curricular algorithms may result in penalties, including for variations of these algorithms outside of the lectures, book, and this post.
- Wikipedia entries are provided for supplemental reading, such as history and discovery of these algorithms. Where differences exist, this document represents the versions used in this course.
- All runtimes are presented assuming $n=|V|$ and $m=|E|$.
- All outputs below are produced as $n$-sized lists, containing an entry for each $v \in V$, and are able to be **indexed by vertex** in $O(1)$ time to read its contents, unless otherwise noted.

## Depth-First Search (DFS)
> https://en.wikipedia.org/wiki/Depth-first_search

**Input**
- A simple graph in adjacency list format
- A starting vertex
	- This is optional, if not provided, DFS will start from an arbitrary location
	- This is accomplished through adjacency list ordering, which we assume takes place when you provide a starting vertex.

**Internal** (not accessible after execution)
- `visited[]`
	- A list containing whether the indexed vertex was touched by DFS
	- All entries of this list will always be set to `true` when DFS completes.
	- This is populated by Explore, an internal subroutine of DFS

**Output**
- `ccnum[]`
	- A list containing the connected component number of the indexed vertex.
	- Vertices reachable from the starting vertex will have a connected component number of 1.
	- Only useful for **undirected** graphs.
- `prev[]`
	- A list containing the parent vertex of each indexed vertex.
	- This can be used to create a path from the starting vertex to any reachable vertex.
	- Unreachable vertices and the starting vertex have a parent of `nil`
- `pre[]`
	- A list containing the pre-visit number for the indexed vertex.
	- Only useful for **directed** graphs.
- `post[]`
	- A list containing the post-visit number for the indexed vertex
	- Only useful for **directed** graphs.

**Runtime**: $O(n+m)$

**Implementation Details**
- DPV pp 83-91
- GR1.3
- GR1.6

**Common Uses**
- Finding connected components of a graph.
- Finding a cycle in a graph.
- Producing a arbitrary path from a starting vertex to a reachable vertex.

## Topological Sort
> https://en.wikipedia.org/wiki/Topological_sorting

**Input:** A simple, directed, acyclic graph (DAG) in adjacency list format.

**Output**
- `order[]`
	- A list of vertices, sorted in topological ordering from source to sink.
	- This output is indexed numerically rather than by vertex.
- All **outputs** from the run of **Depth First Search** are also available

**Runtime:** $O(n+m)$

**Implementation Details**
- DPV pp 89-91
- GR1.10

**Common Uses**
- Finding a topological sorting of a DAG

## Strongly Connected Components (SCC)
> https://en.wikipedia.org/wiki/Strongly_connected_component

**Input:** A simple, directed graph is adjacency list format.

**Output**
- `G_SCC=(V_SCC, E_SCC)`
	- The strongly-connected components metatgraph, provided in adjacency list format
	- By construction, the metagraph is a DAG with vertices sorted from sink to source
	- This ordering is known as reverse topological ordering.
- All outputs from the final run of **Depth-First Search (DFS)** are also available to you.
	- This data is used to connect entities in the metagraph to the original input graph.
	- For example, the first vertex in `V_SCC` represents all vertices with `ccnum[v]=1` from the DFS outputs from the original input graph

**Runtime:** $O(n+m)$

**Implementation Details**
- DPV pp 91-95
- GR1.21

**Common Uses**
- Finding strongly connected components in a graph
- Particularly useful for finding source and sink SCCs

## Breadth-First Search (BFS)
> https://en.wikipedia.org/wiki/Breadth-first_search

**Input**
- A simple graph in adjacency list format
- A starting vertex

**Output**
- `dist[]`
	- A list containing the unweighted distance from the starting vertex to the indexed vertex for all vertices in the graph
	- Unreachable vertices have a distance of $\infty$
- `prev[]`
	- A list containing the parent vertex of the indexed vertex
	- This can be used to create a path from the starting vertex to any reachable vertex
	- Unreachable vertices and the starting vertex have a parent of `nil`

**Runtime:** $O(n+m)$

**Implementation Details**
- DPV pp 105-106
- GR1.24

**Common Uses**
- Reachability Analysis
- Unweighted shortest path determination
- Producing a path from a starting vertex to a reachable vertex

## Dijkstra's Algorithm
> https://en.wikipedia.org/wiki/Dijkstra%27s_algorithm

**Input**
- A simple graph in adjacency list format
- A starting vertex
- A list of non-negative edge weights

**Output**
- `dist[]`
	- A list containing the weighted distance from the starting vertex to the indexed vertex for all vertices in the graph
	- Unreachable vertices have a distance of $\infty$
- `prev[]`
	- A list containing the parent vertex of the indexed vertex, which can be used to create a path from the starting vertex to any reachable vertex
	- Unreachable vertices and the starting vertex have a parent of `nil`

**Runtime:** $O((n+m) \space log \space n)$

**Implementation Details**
- DPV pp 109-115
- GR1.24

**Common Uses**
- Reachability Analysis
- Weighted shortest path determination
- Producing a path from starting vertex to a reachable vertex

## Bellman-Ford (BF)
> https://en.wikipedia.org/wiki/Bellman%E2%80%93Ford_algorithm

**Input**
- A simple graph in adjacency list format
- A starting vertex
- A list of edge weights

**Output**
- `dist[]`
	- A list containing the weighted distance from the starting vertex to the indexed vertex for all vertices in the graph
	- Unreachable vertices have a distance of $\infty$
	- Values are based on the $(n-1)$-th iteration
- `prev[]`
	- A list containing the parent vertex of the indexed vertex.
	- Can be used to create a path from the starting vertex to any reachable vertex.
	- Unreachable vertices and the starting vertex have a parent of `nil`.
- `iter[][]`
	- A 2D list containing the first indexed iteration's shortest path from the starting vertex to the second indexed vertex.
	- For example, `iter[3][v]` contains the distance from the starting vertex to `v` at the end of the 3rd iteration.
	- This stable contains iterations 0 through `n`

**Runtime:** $O(nm)$

**Implementation Details**
- DPV pp 115-119
- DP3.6

**Common Uses**
- Reachability Analysis
- Weighted shortest path determination
- Negative cycle detection
- Producing a path from starting vertex to a reachable vertex.

## Floyd-Warshall (FW)
> https://en.wikipedia.org/wiki/Floyd%E2%80%93Warshall_algorithm

**Input**
- A simple graph in adjacency list format
- A list of edge weights

**Output**
- `dist[][]`
	- A 2D list containing the weighted distance from the first indexed vertex to the seconded indexed vertex
	- `dist[u][v]` contains the shortest path from $u$ to $v$
	- Unreachable vertex pairs have a distance of $\infty$
	- Values are based on the $n$-th iteration
- `iter[][][]`
	- A 3D list
		- idx1: iteration number $i$
		- idx2: index of vertex $u$
		- idx3: index of vertex $v$
		- value: shortest path from $u$ to $v$ at iteration $i$
	- `iter[3][u][v]` contains the distance from $u$ to $v$ at iteration 3
	- Table contains iterations 0 through $n$ (n+1 layers, n rows, n columns)

**Runtime:** $O(n^3)$

**Implementation Details**
- DPV pp 172-173
- DP3.17

**Common Uses**
- Reachability Analysis
- Weighted shortest path determination
- Negative cycle detection

## Kruskal's
> https://en.wikipedia.org/wiki/Kruskal%27s_algorithm

**Input**
- A simple, connected, **undirected** graph in adjacency list format
- A list of edge weights

**Output:*
- `edges[]` - A list of $n-1$ edges that represent a minimum spanning tree for the input graph.

**Runtime:** $O(m \space log \space n)$

**Implementation Details**
- DPV pp 128-137
- GR3.6

**Common Uses:** Producing a minimum spanning tree (adjacency list notation)

## Prim's
> https://en.wikipedia.org/wiki/Prim%27s_algorithm

**Input**
- A simple, connected, undirected graph in adjacency list format
- A list of edge weights

**Output**
- `prev[]`
	-  A list containing the parent vertex of the indexed vertex, which represent the connecting edges of a minimum spanning tree for the input graph.
	- The starting vertex is chosen arbitrarily and has a parent of `nil`

**Runtime**: $O(m \space log \space n)$

**Implementation Details**
- DPV pp 137-139
- GR3.15

**Common Uses:** Producing a minimum spanning tree (vertex-index notation)

## Ford-Fulkerson (FF)
> https://en.wikipedia.org/wiki/Ford%E2%80%93Fulkerson_algorithm

**Input**
- A simple, connected, directed graph in adjacency list format
- A list of positive, integer edge capacities
- A starting source vertex
- A terminating sink vertex

**Output**
- `flow[]` - A list of edges representing the amount capacity used per each indexed edge such that the flow is maximized from the starting vertex to the terminating vertex
- `C` - The value of the maximum flow from the starting vertex to the terminating vertex.

**Runtime:** $O(mC)$

**Implementation Details**
- DPV pp 198-204
- MF1.14

**Common Uses**
- Finding max flows on a graph

## Edmonds-Karp (EK)
> https://en.wikipedia.org/wiki/Edmonds%E2%80%93Karp_algorithm

**Input**

## 2-SAT
> https://en.wikipedia.org/wiki/2-satisfiability

**Input**: A boolean formula
- Conjunctive Normal Form (CNF)
- Each clause contains at most 2 literals
- The formula is backend by a list of `n` variables, representing at most `2n` literals and `m` clauses.

**Output**
- `assignments[]`
	- A list indexable by the variables that back the original input formula
	- Each index assigns either True of False to each backing variable.
	- If the input is not satisfiable, the algorithm instead returns "No"
- Also returns all outputs from the **Strongly Connected Components (SCC)** algorithm.

**Runtime:** $O(n+m)$

**Implementation Details**
- DPV p 101
- GR2

**Common Uses**
- Example of how graph algorithms can be used to solve a problem that starts in a non-graph domain.
- Converting a graph representation into a boolean formula to determine satisfiability of the task at hand.
