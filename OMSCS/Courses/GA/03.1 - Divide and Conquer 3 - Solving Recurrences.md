# 03.1 - Divide and Conquer 3 - Solving Recurrences
## Examples
Merge Sort
- $T(n)=2T(\frac{n}{2})+O(n)$
- $T(n/2):$ the time cost to sort half the list
- $O(n):$ the time cost to merge the sorted sublists
- $O(n \cdot log(n))$

Naive algorithm for integer multiplication
- $T(n)=4T(\frac{n}{2})+O(n)$
- $O(n^2)$

Improved algorithm for integer multiplication
- $T(n)=3T(\frac{n}{2})+O(n)$
- $O(n^{log_23})$
- $log_23=\frac{log_{10}3}{log_{10}2}=1.5849625$ (MacOS calculator doesn't have arb-base log)
- $O(n^{log_23}) \approx O(n^{1.6})$

Median finding algorithm
- $T(n)=T(\frac{3}{4}n)+O(n)$
- $O(n)$

## Example 1
$T(n)=4T(n/2)+O(n)$

For some constant $c > 0:$
- $T(n) \le 4T(n/2)+cn$
- $T(1) \le c$
- $T(n) \le cn + 4T(n/2)$
- $... \le cn + 4\left[4T(n/(2^2)+c(n/2)\right]$
	- $= cn(1+4/2)+4^2T(n/(2^2))$
- $... \le cn(1+4/2) + 4^2\left[ 4T(n/(2^3) + c(n/(2^2)) \right]$
	- $= cn(1+(4/2)+(4/2)^2) + 4^3T(n/(2^3))$

Note that we're starting to get a geometric series. By substituting in 2 times and using $cn$ to replace $O(n)$:

- $T(n)=4T(n/2)+O(n)$
- $T(n) \le cn(1+(4/2)+(4/2)^2) + 4^3T(n/(2^3))$

We keep the $(4/2)^x:0 \le x \lt \infty$ -chain un-simplified so that it's easier to see the geometric series that arrises, and also see how that relates back to the original recurrence. If we substitute the equation into itself $i$ times, we should get:

$$T(n)\le cn\left(1+\left(\frac{4}{2}\right)+\left(\frac{4}{2}\right)^2+...+\left(\frac{4}{2}\right)^{i-1}\right)+4^iT\left(\frac{n}{2^i}\right)$$

When do we stop? let $i=log_2n$ then $\frac{n}{2^i}=1$
$$T(n)\le cn\left(1+\left(\frac{4}{2}\right)+\left(\frac{4}{2}\right)^2+...+\left(\frac{4}{2}\right)^{log_2n-1}\right)+4^{log_2n}T\left(1\right)$$

The last term $\left(\frac{4}{2}\right)^{log_2n-1}$ dominates. Now we can analyze the big-O complexity of the result.

- $cn=O(n)$
- $\left(1+\left(\frac{4}{2}\right)+\left(\frac{4}{2}\right)^2+...+\left(\frac{4}{2}\right)^{log_2n-1}\right)$
	- $=O((\frac{4}{2})^{log_2n})$
	- we can omit the $-1$ from $log_2n$, since big-O hides nuance
	- $=O(n^2/n)$
	- $=O(n)$
- $4^{log_2n}T(1)$
	- $=(2*2)^{log_2n}c$
	- $=2^{log_2n}*2^{log_2n}*c$
	- $=n*n*c$
	- $=O(n^2)$
- $T(n)=O(n)*O(n)+O(n^2)=O(n^2)$

> The key element of these recurrences is the geometric series which arrises.

## Geometric Series
For constant $\alpha \gt 0$, $$F(\alpha, k)=\sum_{j=0}^{k}\alpha^j=1+\alpha+\alpha^2+...+\alpha^k$$
- If $\alpha \gt 1:F(\alpha,k)=O(\alpha^k)$
- If $\alpha = 1:F(\alpha,k)=O(k)$
- If $\alpha \lt 1:F(\alpha,k)=O(1)$

## Manipulating Polynomials
- $4^{log_2n}=2^{log_2n}*2^{log_2n}=n^2$
- $3^{log_2n}=n^c$
	- What is $c$?
	- $3=2^{log_23}$
	- $3^{log_2n}=(2^{log_23})^{log_2n}$
	- $3^{log_2n}=2^{log_23 \times log_2n}$
	- $3^{log_2n}=(2^{log_2n})^{log_23}$
	- $3^{log_2n}=n^{log_23}$

Does this work for every non-trivial $a^{log_bn}$?
- $a^{log_bn}=n^c$
- $a=b^{log_ba}$
- $a^{log_bn}=(b^{log_ba})^{log_bn}$
- $a^{log_bn}=(b^{log_bn})^{log_ba}$
- $a^{log_bn}=n^{log_ba}$

## Example 2
$$T(n)=3T(n/2)+O(n)$$
- $T(n) \le cn + 3T(n/2)$
- $T(n) \le cn(1+(3/2)+(3/2)^2+...+(3/2)^{i-1})+3^iT(n/(2^i))$
- let $i=log_2n$, because that's how we get to the base-case $T(1)$
- $T(n) \le cn(1+(3/2)+(3/2)^2+...+(3/2)^{log_2n-1})+3^{log_2n}T(1)$

## General Recurrence
- Constants
	- $a > 0$
	- $b > 1$
- $T(n)=aT(n/b)+O(n)$
- $T(n)=cn(1+(a/b)+(a/b)^2+...+(a/b)^{log_bn-1})+a^{log_bn}T(1)$
- if $a < b:T(n)=O(n)$
- if $a = b:T(n)=O(n \space log(n))$
- if $a > b:T(n)=O(n^{log_ba})$
