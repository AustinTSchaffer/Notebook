# 00.7 - Common Course Runtimes
This is an enumeration of common big-O notation runtimes that will be relevant for this course. A lot of this duplicates content from [[00.1 - Big-O Notation]]

## Lists
- Creating an empty list: $O(1)$
- Creating a list with initial contents: $O(n)$
- Adding an item to a list (appending): $O(1)$
- Adding an item to a specific non-tail location of a list: $O(n)$
- Remove an item from a list: $O(1)$
	- swap element at $i$ with tail
	- pop tail
- Remove an item from a list (maintain original list order): $O(n)$
- Check the length of a list (counting): $O(n)$
- Check if a list contains an element (scanning): $O(n)$

## Hash Tables
> Hash tables, hash sets, maps, and sets

It's common practice in software to consider these data structures as having magical runtime performance. Within the context of algorithm study and development, we use the worst-case time complexity for any given operation, rather than the amortized runtime of those operations.

- Creating an empty hash table: O(1)
- Creating a hash table with initial contents: $O(n^2)$
- Adding an item to a hash table: $O(n)$
- Remove an item from a hash table: $O(n)$
- Check the length of a hash table (counting): $O(n)$
- Check if a hash table contains an element (scanning): $O(n)$

## Graphs
In this course, we will always treat graphs as adjacency lists, with an indexable list of vertices each pointing to a linked list of adjacent vertices. You can assume you know $n=|V|$ and $m=|E|$.

- Traversing a graph
	- $O(n+m)$
	- Includes reversing, copying, subgraphing
	- Includes anything that requires working with all vertices and edges in a graph
- Operating on a single vertex $v$
	- $O(1)$
	- Includes find, read, removal
	- This assumes you already have access to the vertex or edge itself.
	- You have already paid the runtime costs for finding that vertex.
- Operating on all (or a subset of) vertices $V' \subseteq V$
	- $O(n)$
	- Includes find, read, removal
- Operating on a single edge: $e=(u,v)$
	- $O(n)$
	- This is due to the need to traverse up to $n$ vertices in the adjacency list for vertex $u$ to find and operate on adjacency $v$.
	- Includes find, read, removal.
	- This assumes you already have access to the edge itself.
	- You have already paid the runtime costs for finding that edge.
- Operating on all edges $|E|$
	- $O(n+m)$
	- Includes, find, read, removal
- Accessing properties of an edge or vertex
	- $O(1)$
	- This assumes you already have access to the vertex or edge itself.
	- You have already paid the runtime costs for finding that vertex or edge.
	- weight, color, cost, capacity, label, metadata, etc
- Simplifications
	- If you know something about the connectivity of the graph, it is possible to simplify some runtimes.
	- If the graph is fully connected
		- $m \ge n-1$
		- $O(n+m)=O(m+m)=O(2m)=O(m)$
	- If the graph is a clique
		- $m=n(n-1)/2=O(n^2)$
		- $O(n+m)=O(n+n^2)=O(n^2)$
