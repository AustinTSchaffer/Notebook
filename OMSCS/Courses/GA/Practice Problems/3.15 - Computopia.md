## Claim 1
### Algorithm
We first model the city of Computopia as a graph. In this formulation of the problem, we model intersections as vertices, and we model a one-way road between intersections as a directed edge from one vertex to another. We call this graph $G$.

In order to determine whether it's possible to navigate from any intersection to any other intersection, we need to determine whether all of the vertices of $G$ form a single strongly connected component. To accomplish this, we invoke the SCC algorithm, and check to see if the metagraph of $G$ contains only a single node.

### Justification of Correctness
In a strongly connected component (SCC), all of the vertices in the component can be reached from all of the other vertices in the component. If a graph has only one SCC, then all of the vertices in the whole graph can reach all of the other vertices in the graph.

### Runtime Analysis
The SCC algorithm runs in linear time: $O(n+m)$. Checking to see whether the metagraph of $G$ only contains one node is an $O(1)$ operation.

## Claim 2
### Algorithm
We once again run the SCC algorithm on $G$. From the results of the SCC algorithm, we use `ccnum[]` to get the CC number of city hall (CH). This CC number gets us all of the nodes which are within the same SCC as CH. From the metagraph, we lookup the meta-vertex identified by that CC number. If that meta-vertex has no outgoing edges, then all of the nodes reachable from CH can also reach CH.

### Justification of Correctness
Given that the original claim is false, $G$ will contain more than one SCC. Now, we're trying to find whether all of the nodes reachable from CH can also reach CH. This is effectively asserting that CH exists within a "sink" SCC of the directed graph of Computopia's road network. A "sink" SCC can have incoming edges, but has no outgoing edges, therefore, it's impossible for a vertex within the SCC to reach a vertex that's outside of the SCC.

### Runtime Analysis
The SCC algorithm runs in linear time: $O(n+m)$. Finding the CC number for CH is a $O(1)$ operation. Indexing the correct metanode from $G_{SCC}$ has $O(1)$ time complexity. Determining whether that metanode has 0 outgoing edges is an $O(1)$ operation.

The overall runtime is $O(n+m)$.
