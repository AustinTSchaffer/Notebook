This one seems to come out of left field. It's unclear where to even start, given the lecture materials on DP so far. Let's start by enumerating some definitions.

- **Input:** A dictionary of keywords and their relative frequencies, given as word/frequency pairs. We can encode this with 2 arrays, $W$ and $F$. Elements of $W$ simply symbolize each word using a useful mathematical notation.
	- $W=\{w_1, \space ..., \space w_n\}$
	- $F=\{f_1, \space ..., \space f_n\}$
- **Output:** A binary search tree (BST), with leaves $L=W$. The depth of each keyword can be expressed as $D=\{d_1, \space ..., \space d_n\}$, where $d_i$ is the depth at which $w_i$ is found in the tree. The returned tree must minimize the average lookup cost over the keywords: $$cost=\sum_{i=1}^nd_if_i$$ while still forming a valid BST.

## Official Solution
### Subproblem Definition
$T(i,j) =$ minimum cost to look up words $i, i+1, .., j$

### Recursive Relation
- **Base Cases**
	- The cost to lookup a word $i$ in a tree consisting of only that one word:  $T(i, i) = p[i]$, where $1 \le i \le n$
	- The cost to lookup any word in a tree with 0 nodes: $T(i, i-1) = 0$, where $1 \le i \le n+1$
- **Recursive Case:** $T(i, j) = sum\{p[i..j]\} + min\{T(i, k-1) + T(k+1, j) : i \le k \le j\}$, where $1 \le i \lt j \le n$

### Implementation Analysis
1. State the number of subproblems: $O(n^2)$
2. State the runtime for table fill: $O(n^3)$
3. State how the return is extracted: return $T(1, n)$
4. State the runtime of that return extraction: $O(1)$

### Notes
In this solution, "depth" $d$ is handled implicitly. At each step $T(i, j)$, the sum of the probabilities of words $i$ to $j$ are recomputed ($sum\{p[i..j]\}$). This helps contribute to the $O(n^3)$ runtime. It would be possible to build and cache those sums in $O(n^2)$ time by using a separate $Sum(i,j)$ DP table.

Regardless, it doesn't appear possible to perform this algorithm in $O(n^2)$ time, due to the next term $min\{T(i, k-1) + T(k+1, j) : i \le k \le j\}$. For each $i,j$ pair, we need to iterate over the range $i..j$ to determine the minimum tree.
