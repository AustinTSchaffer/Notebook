This one seems to come out of left field. It's unclear where to even start, given the lecture materials on DP so far. Let's start by enumerating some definitions.

- **Input:** A dictionary of keywords and their relative frequencies, given as word/frequency pairs. We can encode this with 2 arrays, $W$ and $F$. Elements of $W$ simply symbolize each word using a useful mathematical notation.
	- $W=\{w_1, \space ..., \space w_n\}$
	- $F=\{f_1, \space ..., \space f_n\}$
- **Output:** A binary search tree (BST), with leaves $L=W$. The depth of each keyword can be expressed as $D=\{d_1, \space ..., \space d_n\}$, where $d_i$ is the depth at which $w_i$ is found in the tree. The returned tree must minimize the average lookup cost over the keywords: $$cost=\sum_{i=1}^nd_if_i$$ while still forming a valid BST.
