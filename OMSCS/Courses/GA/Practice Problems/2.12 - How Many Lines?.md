# 2.12 - How Many Lines?
![[Pasted image 20260207104237.png]]

At each level of the recursive tree, the algorithm splits $n$ in 2, and processes 2 copies of $n/2$. This is $T(n)=2T(n/2)+O(1)$. The runtime of that form is $O(n)$. Therefore the program prints $\Theta(n)$ lines. We can test this pretty easily.

```python
>>> def two_dot_twelve(n):
...     if n > 1:
...         result = 1
...         result += two_dot_twelve(n/2)
...         result += two_dot_twelve(n/2)
...         return result
...     return 0
...
>>> two_dot_twelve(32)
31
>>> two_dot_twelve(64)
63
>>> two_dot_twelve(128)
127
```
