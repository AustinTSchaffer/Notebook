# 8.10e - NP-C Generalization - Sparse Subgraph
> Given a graph and two integers $a$ and $b$, find a set of $a$ vertices of $G$ such that there are at most $b$ edges between them.

This is the exact opposite of [[8.10d - NP-C Generalization - Dense Subgraph]], so we can solve it by reversing $G$.

## SS is in NP
A solution to a SS problem instance contains a set of vertices $S$. We can validate that this set of vertices is of length $a$ in $O(|V|)$ time.

Next, we need to perform this operation-

$$b \ge \Big|\big(u,v\big) \in E\space:\space \big(u \in S\big) \wedge \big(v \in S\big)\Big|$$

-which runs in some polynomial-bounded time.

Therefore, SS is in NP.

## Clique $\rightarrow$ SS
A not so obvious NP-Complete algorithm that can be reduced to SS is Clique. This reduction will prove that SS is in NP-Hard.
### Input Transformation
Take an instance $I=(G=(V,E),g)$ of a Clique problem, where $G$ is some undirected graph and $g$ is the target clique size. We create an instance $I'=(G',a,b)$ of a DS problem by setting:

- $G'=\overline{G}=(V,\overline{E})$
- $a=g$
- $b=0$

$\overline{E}$ is the set of edges which are not in $G$.

All of these operations are constant-time in $|I|$.

### Output Transformation
Just return $S$.
### Justification
If the Clique problem has a solution, then the SS problem as a solution. A Clique of size $g$ has $g$ vertices that are all fully-connected with each other. In the inverse graph $\overline{G}$, those $g$ vertices will have 0 edges between them. Therefore, $g$ is a solution to the SS problem instance $I'=(\overline{G},a=g,b=0)$.

If the SS problem has a solution, then the Clique problem has a solution. If the SS problem has a solution, then we've found a subgraph of $\overline{G}$ which has $g$ vertices and 0 edges. In $G$, that subgraph has $g(g-1)/2$ edges, making it a fully-connected subgraph. We colloquially call such a subgraph "a clique," making $S$ a solution to the Clique problem.

Therefore, the SS problem has a solution iff the Clique problem has a solution. Since we can reduce a Clique problem to a SS problem, that proves that the SS problem is in NP Hard.

## Conclusion
We have proven that the Sparse Subgraph problem is in NP and is also in NP-Hard. Therefore, the Sparse Subgraph problem is NP-Complete.
