# 4.14 - Shortest Path through Vertex
![[Pasted image 20260302163631.png]]

## Algorithm
- Create reversed graph $G^R=(V,E^R)$
- Run Dijkstra's Algorithm from $v_0$ in $G^R$, to produce $Dist_R$ and $Prev_R$.
- Run Dijkstra's Algorithm from $v_0$ in $G$, to produce $Dist_F$ and $Prev_F$.
- For all $s \in V$
	- the shortest distance from $s$ to $v_0$ can be found by using $Dist_R[s]$
	- the shortest path from $s$ to $v_0$ can be reconstructed using $Prev_R$
- For all $t \in V$
	- the shortest distance from $v_0$ to $t$ can be found by using $Dist_F[t]$
	- the shortest path from $v_0$ to $t$ can be reconstructed using $Prev_F$
- the shortest path from $s$ to $t$ which includes $v_0$ can be found by combining those results.

## Correctness
The shortest path from $s$ to $t$ which passes through $v_0$ is the same thing as finding the shortest path from $s$ to $v_0$ and the shortest path from $v_0$ to $t$. We can find the shortest path from $v_0$ **to** any $t$ with an uncomplicated Dijkstra's algorithm from $v_0$. We can find the shortest path to $v_0$ **from** any $s$ by running Dijkstra's algorithm from $v_0$ on a reversed graph.

## Runtime
- Time to reverse $G$ to produce $G^R$: $O(n+m)$
- Time to run Dijkstra's on $G$ from $v_0$: $O((n+m) \space log \space n)$
- Time to run Dijkstra's on $G^R$ from $v_0$: $O((n+m) \space log \space n)$
- Time to reconstruct the path from $s$ to $v_0$: $O(n)$
- Time to reconstruct the path from $v_0$ to $t$: $O(n)$

Overall Runtime: $O((n+m) \space log \space n)$
