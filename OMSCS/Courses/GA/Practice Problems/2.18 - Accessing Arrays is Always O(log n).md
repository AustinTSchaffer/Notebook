# 2.18 - Accessing Arrays is Always O(log n)
![[Pasted image 20260207132028.png]]

The big-omega ($\Omega$) notation is asking why the **best-case** scenario for searching for a value in $A$ is $log \space n$. When using comparisons on values from $A$, where $A$ is sorted, at best, we reduce the problem size from $n$ to $n/2$. The runtime complexity of algorithms of this form is shown below.

$T(n)=T(n/2)+O(1)=O(log \space n)$
