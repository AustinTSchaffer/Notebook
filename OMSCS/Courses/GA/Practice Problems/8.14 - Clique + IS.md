# 8.14 - Clique + IS
> Prove that the following problem is NP-complete: given an undirected graph $G=(V,E)$ and an integer $k$, return a clique of size $k$ as well as an independent set of size $k$, provided both exist.

Can be reduced from IS or Clique. Copy $V$ twice, making $V_{C}$ and $V_{IS}$. Create $G'_C=(V,E)$ and $G'_{IS}=(V,\overline{E})$. Create $G'=G'_C \cup G'_{IS}$. The 2 subgraphs which were unioned to form $G'$ should be disjoint from each other. $G'$ may have more than 2 connected components, depending on the topologies of $G$ and $\overline{G}$.

We can now reduce either problem to C+IS, just by selecting which set of vertices to return back to the encapsulating problem.

This works because Clique and IS are exact opposite problems. We have already shown that one can be reduced to the other by inverting $G$ ([[06.5 - NP - Graph Problems]]). Therefore, if we have a graph which contains both $G$ and $\overline{G}$, then we can solve both problems at the same time.
