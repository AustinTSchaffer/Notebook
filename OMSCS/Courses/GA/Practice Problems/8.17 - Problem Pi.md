# 8.17 - Problem Pi
> Show that for any problem $\Pi$ in NP, there is an algorithm which solves $\Pi$ in time $O(2^{p(n)})$, where $n$ is the size of the input instance and $p(n)$ is a polynomial (which may depend on $\Pi$).

For every problem $\Pi$ in NP, there exists an algorithm of order $O(q(n))$ which can validate a given solution to $\Pi$, where $q$ is polynomial. $n$ is the size of the instance $I$ of $\Pi$ ($|I_{\Pi}|=n$).

However, we might not need any of that knowledge.

Every problem in NP can be reduced to an instance $I'$ of a 3-SAT problem in $O(a(n))$ time, where $a$ is a polynomial.

- $I'$ will have $O(b(n))$ variables, where $b$ is a polynomial.
- $I'$ will have $O(c(n))$ clauses, where $c$ is a polynomial.

Any solution to $I'$ will then need to be translated back to a solution to problem $\Pi$. This will take $O(d(n))$ time, where $d$ is a polynomial.

We now need to find a solution to the 3-SAT problem instance. This can be accomplished naively by trying all $2^{b(n)}$ possible assignments to the $b(n)$ variables of $I'$, and by running the $O(c(n))$ algorithm required to validate the clauses of $I'$ given an arbitrary assignment. The overall runtime of this algorithm is $O(2^{b(n)} \cdot c(n))$. Thankfully we don't live in a naive world, and there exists algorithms for solving 3-SAT in $O(g^n)$ time, where $g < 2$.

Thus, we have demonstrated that we can solve any problem in NP of size $n$ with the following time complexity:

$$O(a(n))+ O(g^{b(n)}) + O(d(n)) = O(g^{b(n)}) < O(2^{p(n)})$$

Where $a$, $b$, $d$, and $p$ are polynomial, and $g < 2$.
