# 6.1 - Contiguous Subsequence
![[6.1 - Contiguous Subsequence.png]]

$S=5,15,-30,10,-5,40,10$

- Input: A list of numbers $A$
- Output: The contiguous subsequence of maximum sum

## Step 1: Define Subproblem in Words
```
for i=1 -> n
let CS(i) = the max sum substring in a_1, ..., a_i which includes a_i
```

## Step 2: Define Recurrence Relation
- if $A_{i-1}<A_i$
	- $S(i)=A_i+max\{0, S(i-1)\}$
- else
	- $S(i) = A_i$

## Code
```python
def contiguous_subseq(A: list[int]) -> tuple[int, list[int]]:
    """
    Returns the maximum sum of the larget contiguous subsequence of A.
    """
    S = [0] + [0 for _ in A]

    for i in range(len(A)):
        if i > 0:
            S[i+1] = A[i] + max(0, S[i])
        else:
            S[i+1] = A[i]

    idx_max = 0
    max_ = 0
    for s_idx, s in enumerate(S):
        if s > max_:
            max_ = s
            idx_max = s_idx-1

    # Reconstruct max substring
    sum_ = 0
    substring: list[int] = []
    for i in range(idx_max, -1, -1):
        sum_ += A[i]
        substring.append(A[i])
        if sum_ == max_:
            break

    return max_, list(reversed(substring))

```
