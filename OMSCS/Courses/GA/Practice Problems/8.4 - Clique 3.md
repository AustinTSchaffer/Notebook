## 8.4a - Clique 3 $\in$ NP
>Prove that CLIQUE-3 is in NP.

The proof that Clique-3 is in NP does not substantially differ from the proof that Clique is in NP. To validate, we need to check that all of the vertices in the resulting clique connect with each other. This has $O(n^2)$ time complexity, where $n$ is the size of the clique. We know that the max size of the clique is bounded by $n=4$, since each vertex in $G$ has at most 3 edges, which is constant regardless of the size of G.

Therefore, the runtime complexity for validating the solution to a Clique-3 problem is $O(1)$.

If we need to also validate the input as part of the proof, then we'll have to check that each vertex in $G$ has degree at most 3. To do this, we'll have to iterate over all vertices in G, and count the number of edges. If any vertex has at least 4 edges, then $G$ is not a valid input to Clique-3. This requires that we count up to 4 for each vertex, making this validation $O(n)$, which dominates the $O(1)$ solution validation runtime.

## 8.4b - Incorrect Proof
> We know that the CLIQUE problem in general graphs is NP-complete, so it is enough to present a reduction from CLIQUE-3 to CLIQUE. Given a graph G with vertices of degree ≤ 3, and a parameter g, the reduction leaves the graph and the parameter unchanged: clearly the output of the reduction is a possible input for the CLIQUE problem. Furthermore, the answer to both problems is identical. This proves the correctness of the reduction and, therefore, the NP-completeness of CLIQUE-3.

This proof reduces Clique-3 to Clique, which is the opposite direction required for proving the NP-completeness of Clique-3. We can always solve a problem in NP with an algorithm that works on a harder NP problem. Therefore, this implication is not enough to prove that Clique-3 is NP-complete.

## 8.4c - Vertex Cover
> It is true that the VERTEX COVER problem remains NP-complete even when restricted to graphs in which every vertex has degree at most 3. Call this problem VC-3. What is wrong with the following proof of NP-completeness for CLIQUE-3?
>
> We present a reduction from VC-3 to CLIQUE-3. Given a graph $G=(V,E)$ with node degrees bounded by 3, and a parameter $b$, we create an instance of CLIQUE-3 by leaving the graph unchanged and switching the parameter to $|V|−b$. Now, a subset $C \subseteq V$ is a vertex cover in $G$ if and only if the complementary set $V−C$ is a clique in $G$. Therefore $G$ has a vertex cover of size $\le b$ if and only if it has a clique of size $\ge |V|−b$. This proves the correctness of the reduction and, consequently, the NP-completeness of CLIQUE-3.

From the TAs

> The reduction is incorrect. Specifically, the statement "a subset $C \subseteq V$ is a vertex cover in 𝐺 if and only if the complementary set $V-C$ is a clique in the same graph 𝐺" is incorrect. While it would be correct to say "a subset 𝐶 ⊆ 𝑉 is a vertex cover in 𝐺 if and only if the complementary set 𝑉 − 𝐶 is a clique in the complementary graph $\overline{G}=(V,\overline{E})$", $\overline{G}$ is not guaranteed to retain the property that every vertex has at degree at most 3, so this alternate statement is not useful for the desired reduction.

The TA rationale seems solid to me. We have to follow the chain of reductions from [[06.5 - NP - Graph Problems]] in order to reduce Vertex Cover to IS to Clique. This falls apart, because the proposed proof doesn't do this correctly. When the reduction is corrected, it's possible that the input to Clique-3 doesn't follow the input restrictions imposed by Clique-3.
