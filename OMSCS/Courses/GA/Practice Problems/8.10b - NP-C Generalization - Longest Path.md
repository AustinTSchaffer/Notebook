# 8.10b - NP-C Generalization - Longest Path
> Given a graph G and an integer g, find in G a simple path of length g.

The name of this problem is misleading. We're not trying to find the longest path. We're trying to find a path of length $g$. Therefore, we will refer to this problem as the g-Path problem for the remainder of this document.

## Longest Path is in NP
- We can validate that the path exists in G in $O(n+m)$ time.
- We can find the length of a given simple path in $O(n)$ time.
- We can validate that the determined length of the path equals $g$ in $O(1)$ time.

Therefore, g-Path is in NP.

## Rudrata Path $\rightarrow$ Longest Path
We will be proving that the g-Path problem is in NP-Hard by demonstrating a reduction from the Rudrata Path problem.
### Input Transformation
An instance $I$ of a Rudrata Path problem contains a graph $G=(V,E)$. We can create the goal $g$ of an instance $I'$ of a $g$-Path problem by setting $g=n$.

If we need edge weights, we can make a table of edge weights $W$ where every edge has weight 1. This requires $O(m)$ time.
### Output Transformation
A solution $S$ to an instance of a $g$-Path problem contains only a path in $G$ of length $g$. We simply return $S$ as the solution to the Rudrata Path problem.
### Justification
If the Rudrata Path problem has a solution, then the g-Path problem has a solution. This is because the Rudrata path touches every vertex once, resulting in a path of length $n$, which satisfies the solution requirements for the g-Path 

If the Rudrata Path problem does not have a solution, then the g-Path problem does not have a solution. In this eventuality, there does not exist a path in $G$ which touches every vertex. Therefore, there cannot exist a path of length $n$ in $G$, since that would imply that there in fact does exist a simple Rudrata Path in $G$.

Therefore, the Rudrata Path problem has a solution iff the g-Path problem has a solution.

Since the Rudrata Path problem can be reduced to the g-Path problem, the g-Path problem is in NP-Hard.

## Conclusion
The $g$-Path problem has been shown to be in both NP and NP-Hard, therefore the $g$-Path problem must be in NP-Complete.
