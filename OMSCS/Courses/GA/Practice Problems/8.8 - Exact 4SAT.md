# 8.8 - Exact 4SAT
> In the EXACT 4SAT problem, the input is a set of clauses, each of which is a disjunction of exactly four literals, and such that each variable occurs at most once in each clause. The goal is to find a satisfying assignment, if one exists. Prove that EXACT 4SAT is NP-complete.

## Exact 4SAT $\in$ NP
To validate Exact 4SAT, we iterate over $m$ clauses and check to make sure that at least one of the clause's 4 literals is satisfied. This runs in $O(m)$ time. Therefore, Exact 4SAT is in NP.

## 3SAT $\rightarrow$ Exact 4SAT
To prove that Exact 4SAT is in NP-Complete, we will perform a reduction from 3SAT to Exact 4SAT.

### Input Transformation
To translate an instance of 3-SAT into an instance of Exact 4SAT, we must convert all possible 3SAT clauses to equivalent Exact 4SAT clauses.

For an input 3SAT clause $c_i$ of size 3, of format $(a \vee b \vee c)$, we introduce a new variable $y_{i,1}$, and project $c_i$ into 2 conjuncted Exact 4SAT clauses. The resulting clauses have this format:

- $(a \vee b \vee c \vee y_{i,1})$
- $\wedge (a \vee b \vee c \vee \overline{y_{i,1}})$

For an input 3SAT clause $c_i$ of size 2, of format $(a \vee b)$, we introduce 2 new variables $y_{i,1}$ and $y_{i,2}$, and project $c_i$ into 4 conjuncted Exact 4SAT clauses. These clauses will have this format:

- $(a \vee b \vee y_{i,1} \vee y_{i,2})$
- $\wedge (a \vee b \vee y_{i,1} \vee \overline{y_{i,2}})$
- $\wedge (a \vee b \vee \overline{y_{i,1}} \vee y_{i,2})$
- $\wedge (a \vee b \vee \overline{y_{i,1}} \vee \overline{y_{i,2}})$

For an input 3SAT clause $c_i$ of size 1, of format $(a)$, we introduce 3 new variables $y_{i,1}$ and $y_{i,2}$ and $y_{i,3}$, and project $c_i$ into 8 conjuncted Exact 4SAT clauses. These clauses will have this format:

- $(a \vee y_{i,1} \vee y_{i,2} \vee y_{i,3})$
- $\wedge (a \vee y_{i,1} \vee y_{i,2} \vee \overline{y_{i,3}})$
- $\wedge (a \vee y_{i,1} \vee \overline{y_{i,2}} \vee y_{i,3})$
- $\wedge (a \vee y_{i,1} \vee \overline{y_{i,2}} \vee \overline{y_{i,3}})$
- $\wedge (a \vee \overline{y_{i,1}} \vee y_{i,2} \vee y_{i,3})$
- $\wedge (a \vee \overline{y_{i,1}} \vee y_{i,2} \vee \overline{y_{i,3}})$
- $\wedge (a \vee \overline{y_{i,1}} \vee \overline{y_{i,2}} \vee y_{i,3})$
- $\wedge (a \vee \overline{y_{i,1}} \vee \overline{y_{i,2}} \vee \overline{y_{i,3}})$

For each 3SAT clause, we must create up to 3 new variables and up to 8 new 4SAT clauses. Therefore, this transformation is linear in the size of the 3SAT problem.

### Output Transformation
If the Exact 4SAT problem instance is not satisfiable, then we return "NO", as that indicates the 3SAT problem instance is also not satisfiable.

Given a satisfying assignment $S$ to the Exact 4SAT instance, we must remove all of the $y$ variables that were introduced, and return the resulting satisfying assignment $S'$ which only includes the variables that exist in the 3SAT instance.

This transformation is linear in the size of the number of variables to the Exact 4SAT instance, which we showed is linear in the size of the 3SAT instance.

### Justification
In order to convert a 3SAT problem into an Exact 4SAT problem, we need to convert each clause into some number of clauses of size exactly equal to 4. For each input clause $c_i$, the number of new clauses needed depends on the number of literals that comprise the clause.

In the case where the input clause $c_i$ has 3 literals, we create 2 clauses, introducing a new variable $y_{i,1}$. This positive literal ($y_{i,1}$) is used in the first clause, and the negative literal ($\overline{y_{i,1}}$) is used in the second clause. All of the literals from $c_i$ are copied into the new clauses as-is. This ensures that the 4SAT clauses are of length 4, and ensures that $y_{i,1}$ is incapable of satisfying both clauses simultaneously.

In the case where the input clause $c_i$ has 2 literals, we perform the same procedure. The only difference is we need 2 variables $y_{i,1}$ and $y_{i,2}$, and 4 clauses, which cannot all be satisfied solely through the literals $y_{i,1}$, $y_{i,2}$, $\overline{y_{i,1}}$, $\overline{y_{i,2}}$.

In the case where the input clause $c_i$ has only 1 literal, we again perform the same procedure. This time we need 3 variables $y_{i,1}$, $y_{i,2}$, and $y_{i,3}$, and 8 clauses, which cannot all be satisfied solely through the literals $y_{i,1}$, $y_{i,2}$,$y_{i,3}$, $\overline{y_{i,1}}$, $\overline{y_{i,2}}$,$\overline{y_{i,3}}$.

Using this reduction from 3SAT, we can prove that Exact 4SAT is NP-Complete.

If there exists a satisfying assignment $S$ for an instance of 3SAT, then there must exist a satisfying assignment $S'$ for the Exact 4SAT problem which is a superset of $S$ ($S \subset S'$). For each clause $c_i$ in an instance of 3SAT, if $c_i$ has a satisfying assignment, then all of the Exact 4SAT clauses which were derived from $c_i$ must also have a satisfying assignment.

If an instance of an Exact 4SAT problem has a satisfying assignment $S$, and that instance was derived from an instance of a 3SAT problem, then the original 3SAT problem instance must have a satisfying assignment $S'$ which is a subset of $S$ ($S \subset S'$). Due to the construction of the clauses, none of the $y$ variables that were introduced to form the Exact 4SAT clauses have any bearing over whether the Exact 4SAT instance is satisfiable.

Therefore, Exact 4SAT is in NP-Complete.
