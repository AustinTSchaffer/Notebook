# 8.19 - Kite
> A kite is a graph on an even number of vertices, say $2n$, in which $n$ of the vertices form a clique and the remaining $n$ vertices are connected in a “tail” that consists of a path joined to one of the vertices of the clique. Given a graph and a goal $g$, the KITE problem asks for a subgraph which is a kite and which contains $2g$ nodes. Prove that KITE is NP-complete.

Seems like a problem where you take a Clique and add a "tail" to every vertex, then remove the tail from $S$.

## Kite is in NP
We can validate a solution $S$ to an instance $I$ of the Kite problem in polynomial time, demonstrating that the Kite problem is in NP.

For this problem, we are assuming that the instance of a Kite problem has the form: $I=(G=(V,E),g)$, and that the solution has the form $G'=(V',E')$.

First, we check that all of the vertices $V'$ returned in the solution exist within $G$. This can be accomplished in $O(n^2)$ time.

We can next check that all of the vertices in $V'$ exist within the same connected component of $G$, showing that all vertices are connected with each other. This can be accomplished by running DFS and checking that all $v' \in V'$ have the same $ccnum$. This requires $O(n+m)$ time.

We can now check the degree of all vertices in $G'$. This requires $O(n+m)$ time. We can use this degree information to identify the clique and the tail in $G'$.

- One vertex will have degree 1. This vertex is the tip of the tail.
- $g-1$ vertices will have degree 2. These vertices are in the tail.
- One vertex will have degree $g$. This vertex is in the clique and is the attachment point for the tail.
- $g-1$ vertices will have degree $g-1$. These vertices are in the clique and do not connect to the tail.

Removing the degree 1 vertex from $G'$ should result in $G''$ which has the following degree distribution.

- One vertex will have degree 1. This vertex is the tip of the tail.
- $g-2$ vertices will have degree 2. These vertices are in the tail.
- One vertex will have degree $g$. This vertex is in the clique and is the attachment point for the tail.
- $g-1$ vertices will have degree $g-1$. These vertices are in the clique and do not connect to the tail.

We can keep applying this procedure to $G'$ $g$ times, which should then result in the clique being isolated. Using a naive algorithm which recalculates all vertex degrees in $G'$ on each iteration, this requires $O(n(n+m))$ time.

This should leave us with a $G''$ which has $g$ vertices and $g(g-1)/2$ edges.

If none of these assumptions are violated during this process, then $G'$ is a kite. All of these steps are polynomial in $|I|$.

## Clique $\rightarrow$ Kite
Blah blah blah Clique reduces to Kite. Kite is in NP-Hard.

### Input Transformation
Consider an instance of a Clique problem: $I=(G=(V,E), g)$. Construct a copy of $G$, called $G'=(V',E')$. This requires $O(|V|+|E|)$ time.

For each vertex in $v \in V$, add a "tail" of length $|V|$ to $G'$. This tail consists of $|V|$ vertices which are connected as a simple path with $|V|-1$ edges. We connect one of the "ends" of that tail to $v$ with a final edge. We will call this set of new vertices $V_T$ for "tails". This adds $|V|^2$ vertices and $|V|^2$ edges to $G'$, requiring $O(|V|^2)$ time.

Construct an instance of a Kite problem: $I'=(G'=(V',E'), g)$.

All of these steps are polynomial in $|G|$ and $|I|$.

### Output Transformation
If the Kite problem instance has no solution, then we return "NO."

Otherwise, the solution to the Kite problem consists of a subgraph of $G'$: $(G_S=(V_S,E_S)) \subseteq G'$ which describes a Kite. We remove all vertices of $V_S$ which are in $V_T$, and then return $V_S'$.

### Justification
If the Clique problem has a solution, then the Kite problem has a solution.

If the Clique problem has a solution, then there exists a clique $C$ of size $g$ in $G$. Our input transformation added $|V|$ artificial tails of length $|V|$ to all vertices in $G$. Therefore in $G'$, this clique has $g$ tails of size $|V| \ge g$. One of these tails plus $C$ suffice as a solution to the Kite problem.

If the Kite problem has a solution, then the Clique problem has a solution. If the Kite problem has a solution, then there exists a Clique of size $g$ in $G'$, with a tail of length $g$. If we remove all of the vertices which comprise the tail of that Kite, then we are left with a Clique of size $g$, which suffices as the solution to the Clique problem.

Therefore, the Kite problem has a solution if-and-only-if the Clique problem has a solution. Therefore, the Kite problem is in NP-Hard.

## Conclusion
We have demonstrated that the Kite problem is in NP and NP-Hard, proving that the Kite problem is in NP-Complete.
