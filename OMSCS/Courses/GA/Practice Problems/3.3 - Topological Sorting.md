# 3.3 - Topological Sorting
![[Pasted image 20260223150450.png]]

| Node | Pre | Post |
| ---- | --- | ---- |
| A    | 1   | 14   |
| B    | 15  | 16   |
| C    | 2   | 13   |
| D    | 3   | 10   |
| E    | 11  | 12   |
| F    | 4   | 9    |
| G    | 5   | 6    |
| H    | 7   | 8    |
- **Sources:** A, B
- **Sinks:** G, H
- **Topological Ordering:** B, A, C, E, D, F, H, G
- **Num Top Orderings:** $2*1*2*1*2=8$

Topological ordering is simply the order of the nodes in reverse order of their post number. In a DAG, every edge leads to a vertex with a lower post number.
