# 6.18 - Making Change
![[Pasted image 20260120154414.png]]

- **Input:**
	- $X=\{x_1,x_2,...,x_n\}:$ a list of coin denominations. Positive integers.
	- $V :$ a target value.
- **Output:**
	- $T$ or $F$, whether $v$ can be made from $X$ without replacement.

## Step 1: Define Subproblem

For 0 <= i <= n
For 0 <= v <= V
MC(i, v) = True if v can be made from some combination of coins X\[0..i\]. False otherwise.

## Step 2: Recurrence Relation

- No change remaining: MC(i, 0) = True : 1 <= i <= n
- Some change remaining, no available coins: MC(0, v) = False : 1 <= v <= V

if X\[i\] <= v
- then: MC(i, v) = OR { MC(i-1, v) , MC(i-1, v-X\[i\]) }
- otherwise: MC(i, v) = MC(i-1, v)

## Algorithm Analysis
1. **Space Complexity:** O(n\*V)
2. **Time Complexity:** O(n\*V)
3. **Extract Result:** MC(n, V)
4. **Time Complexity for Extracting Result:** O(1)
