# 5.7 - Maximum Spanning Tree
> Show how to find the maximum spanning tree of a graph, that is, the spanning tree of largest total weight.

Simply invert the edge weights, then run an MST algorithm. When you invert the edge weights, you convert the minimization problem into a maximization problem. This is a fairly common trick in mathematics and computer science.

As for which inversion strategy to use, negating the edge weights is common and fairly inexpensive.
