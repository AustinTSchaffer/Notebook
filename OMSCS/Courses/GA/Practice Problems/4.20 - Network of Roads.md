# 4.20 - Network of Roads
![[Pasted image 20260314161250.png]]

## Exploration
- We can't use MSTs for this problem, since the question has to do with total driving distance.
- The problem doesn't clarify whether the graph is directed or undirected
- Running Dijkstra's from $s$ would set a good baseline.
- We don't want to run Dijkstra's on all copies of the graph containing some new $e' \in E'$. That would be too expensive.
- We could add all $E'$ to G, making $G'=(V,E \cup E')$. We could run Dijkstra on this new graph and check the shortest path from $s$ to $t$. However, that could result in a shortest path which uses more than one edge from $E'$.
- How do we modify $G$ s.t. only one $e' \in E'$ is used at a time? Is that possible?
	- We could create a new Graph $G'=(V,E)$
	- For each $e'=(u,v) \in E'$
		- Add a new copy of $G$ as a subgraph to $G'$. This subgraph is identified on a per-edge basis: $G_{e'}=(v_{e'} \in V, e_{e'} \in E)$
		- Add an edge to $G'$ to connect subgraph $G$ to subgraph $G_{e'}$. Connect vertex u in $G$ to vertex $v_{e'}$ in $G_{e'}$.
	- Now we can run Dijkstra's from $s$ in $G'$.
	- To get the answer, we can check $\min\{dist[t], dist[t_{e'}] : e' \in E'\}$ to get the answer.
	- This is effectively the same as running Dijkstra $|E'|$ times.

This problem can be made similar to [[4.14 - Shortest Path through Vertex]].

- Run Dijkstra's from $s$ in $G$ to produce $dist_s$
- If $G$ is directed, reverse $G$ to create $G^R$, and run Dijkstra's from $t$ in $G^R$ to produce $dist_t$
- If $G$ is undirected, run Dijkstra's from $t$ in $G$ to produce $dist_t$
- As a baseline, check the distance from $s$ to $t$ with $dist_s[t]$.
- For each potential road $e'=(u,v) \in E'$
	- Check whether $dist_s[u]+l_{e'}+dist_t[v]$ is the best option
	- $argmin_{e'=(u,v) \in E'} \space \{ dist_s[u]+l_{e'}+dist_t[v] \}$
- Choose whichever $e'$ is the best, or return "no" if none of the options for $e'$ reduce the distance from $s$ to $t$.
