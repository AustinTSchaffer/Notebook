# 2.16 - Infinite Array
![[Pasted image 20260128214554.png]]

This is a quick 3-step algorithm.
1. Step 1, we need to find at least one infinity.
2. Step 2, we need to find $n$.
3. Step 3, we need to find $x$.

## Step 1
We can find $n$ in $O(log \space n)$ time with the following procedure. We start $a_1$ at 1, and then check if the value is $\infty$. If it's not, we double it and try again. We continue until we find an $\infty$.

At this point, we have some $A[a_j]=\infty$ and $A[a_{j-1}]<\infty$.

This step runs in $O(log \space n)$ time.

## Step 2
From here we need to find the first index of $A$ which contains $\infty$. One common modification of the binary search algorithm is "finding the **leftmost** matching value." We can use that modification, plus a starting index $a_j$, an ending index $a_{j-1}$, and a search target of $\infty$. Once we find the index $a_k$ of that leftmost $\infty$, we know that $n=a_{k-1}$.

This step runs in $O(log \space n)$ time.

## Step 3
We can now find $x$ by performing a binary search on $A$ with a starting index of 1 an an ending index of $a_{k-1}$.

This step runs in $O(log \space n)$ time.
