# 7.27 - Change-Making Problem
> Show that the change-making problem (Exercise 6.17) can be formulated as an integer linear program. Can we solve this program as an LP, in the certainty that the solution will turn out to be integral (as in the case of bipartite matching)? Either prove it or give a counterexample.

**Input:** $[x_1,x_2,...,x_n];\space v$
**Question:** Is it possible to make change for $v$ using coins of denominations $x_1,...,x_n$?

## ILP Solution
- $\max \space x_1q_1+x_2q_2+...+x_nq_n$
- s.t.
	- $x_1q_1+x_2q_2+...+x_nq_n \le v$
	- $-(x_1q_1+x_2q_2+...+x_nq_n) \le -v$
	- $q_1,q_2,...,q_n \in Z^n$
	- $q_1,q_2,...,q_n \ge 0$

Note from TA solution, the objective function is arbitrary. Really we just need to see if there exists any solutions in the feasible space. We can use $\min\space\{q_1+...+q_n\}$ as a tiebreaker to minimize the number of coins used, in the event there are multiple solutions.

## LP Counterexample
Pretty much every example works as a counterexample for this problem. In the ILP, we use $Q=[q_1,...,q_n]$ as decision variables for the quantity of each coin to use to achieve $v$. Because LP doesn't require that these be integers, we can satisfy the constraint with a fractional amount of any single coin, which doesn't help narrow down the search space whatsoever.
