- **Input:**
	- $X=\{x_1,x_2,...,x_n\}:$ a list of coin denominations. Positive integers.
	- $V :$ a target value.
	- $K:$ the maximum number of coins which can be used number of

### Attempt 2
I saw a reference online to a solution which only used a 1D DP table of size $V$. How would that work? Would $T(v)$ be the minimum number of coins required to achieve a specific $v$ where $0 \le v \le V$?

| v   | $PS(v)$ | $T(v)$ | $CU_{idx}(v)$ | $CU_{val}(v)$ |
| --- | ------- | ------ | ------------- | ------------- |
| 0   | -1      | 0      | -1            | -1            |
| 1   | $TV(0)$ | 1      | $x_1$         | 1             |
| 2   | $TV(0)$ | 1      | $x_2$         | 2             |
| 3   | $TV(0)$ | 1      | $x_3$         | 3             |
| 4   | $TV(1)$ | 2      | $x_3$         | 3             |
| 5   | $TV(2)$ | 2      | $x_2$         | 3             |

That seems to work. Why does this problem only require $O(V)$ space and $O(V \cdot n)$ time, while [[6.18 - Making Change]] requires $O(V \cdot n)$ space AND time? I don't feel that I have an intuitive explanation as to why this problem is "easier" than the 6.18 variant.

This solution is also easily extensible to enable backtracking for assembling the list of $k$ coins that you need to produce $V$. We can further adjust the output to ignore the $T/F$ result type, and instead return the optimal number of coins required to produce $V$ ($\hat{k}$), along with the list of those coins. To enable backtracking, we need to maintain a backtracking table, using one of these designs.

1. Keep track of the prior subproblem index used at each $v$ in a separate table $PriorSubproblem(v)$ or $PS(v)$.
2. Keep track of the index of the coin used at each $v$ in a separate table $CoinUsed_{idx}(v)$ or $CU_{idx}(v)$.
3. Keep track of the value of the coin used at each $v$ in a separate table $CoinUsed_{val}(v)$ or $CU_{val}(v)$.

Options 1 and 3 are equivalent. Both options generate the values of the coins used during backtracking, while Option 2 generates the list of coins used expressed as indices of $X$. All of these options run in $O(V)$ time.
