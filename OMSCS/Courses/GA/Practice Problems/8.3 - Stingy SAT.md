# 8.3 - Stingy SAT
> STINGY SAT is the following problem: given a set of clauses (each a disjunction of literals) and an integer k, find a satisfying assignment in which at most k variables are true, if such an assignment exists. Prove that STINGY SAT is NP-complete.

## Notes
- Stingy SAT is obviously a harder variant of SAT

## Stingy SAT is in NP
### My Work
Given a satisfying assignment $S$, generated by Stingy-SAT, to a CNF formula $f$, we can validate $S$ in polynomial time. First, we can check that the number of true variables in $S$ is $\le k$. This requires $O(n)$ time, where $n$ is the number of variables in $f$. We can then validate that $S$ satisfies $f$ by checking each clause in $f$, to see if the clause contains a single true literal. This requires $O(mn)$ time, where $m$ is the number of clauses in $f$.

This proves that Stingy SAT is in NP.

### TA Wording
> First, we show that STINGY SAT is in NP. Let the input formula be denoted by 𝑓, and let 𝑛 be the number of variables and 𝑚 be the number of clauses. Given a proposed satisfying truth assignment 𝑆 for 𝑓, we can just check clause by clause that 𝑆 satisfies at least one literal in each clause; this takes 𝑂(𝑛) time per clause and thus 𝑂(𝑛𝑚) total time. Then in 𝑂(𝑛) time, we count how many variables are set to be TRUE in 𝑆 and check that the number is larger than 𝑘 or not. Overall, this is dominated by 𝑂(𝑛𝑚) and is thus polynomial.

	- Let the input CNF formula be denoted by $f$.
	- Let $n$ be the number of variables in $m$ be the number of clauses.
- "Given a proposed satisfying assignment $S$ for $f$"
	- More detail on validating each clause.

## SAT $\rightarrow$ Stingy SAT
We will prove that SAT can be reduced to Stingy SAT, proving that Stingy SAT is NP-Complete.

### Input Transformation
In order to convert an instance $I$ of SAT to an instance $I'$ of Stingy SAT, we need to introduce a value for $k$. We can set $k$ equal to the number of variables $n$, which is the max number of variables which can be made true for instance $I$. Then, we pass an unaltered $f$ and $k$ to Stingy SAT.

Setting $k=n$ is an $O(1)$ operation, which is polynomial time.

### Output Transformation
In order to convert a solution to Stingy SAT back to a solution of SAT, we simply return $S$. A satisfying assignment for $f$ and $k$ is a satisfying assignment for $f$.

If Stingy SAT returns NO, then $f$ has no satisfying assignment despite $k$.

### Correctness Justification
From the TA:

> Clearly, every assignment over 𝑛 variables will have at most 𝑛 variables set to TRUE, so this extra restriction will not constrain the set of solutions. Then, if STINGY SAT returns a satisfying assignment, that assignment will also satisfy the original SAT problem. Likewise, if STINGY SAT returns that there is no such assignment, then there can be no solution to the SAT problem.

> Then, since SAT is NP-complete, STINGY SAT must at least as hard as SAT.

> Given that STINGY SAT is in NP and at least as hard as SAT, we conclude that STINGY SAT is NP-Complete.

Here's how the TA solution goes about this problem. First, it proves the problem is in NP by showing how to validate the solution in polynomial time. Next, it picks SAT as the obvious choice of NP-Complete problem, from which to perform the reduction. Next, it defines the input and output transformations without justification. Then, it shows how SAT reduces to Stingy SAT. It does this using the following logical steps:

- The extra restriction imposed upon the SAT problem does not constrain the set of solutions to the SAT problem.
- "If Stingy SAT returns a satisfying assignmentt, that assignment will also satisfy the original SAT problem."
	- This is $B \rightarrow A$
- "Likewise, if Stingy SAT returns that there is no such assignment, then there can be no solution to the SAT problem."
	- This is $\neg B \rightarrow \neg A$, which is the contrapositive of $A \rightarrow B$
- There's some redundancy in how the TA solution declares that $B$ is definitively NP-Complete
	- Since SAT is NP-complete, Stingy Sat must at least be as hard as SAT.
	- Given that Stingy SAT is in NP and at least as hard as SAT, we conclude that Stingy SAT is NP-Complete
