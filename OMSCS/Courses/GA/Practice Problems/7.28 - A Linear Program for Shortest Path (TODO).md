## 7.28a - This is a flow problem?
Let's choose some s-t path $P$ in $G$ and then send 1 unit of flow along only the edges in $P$. We then have some s-t flow $f$ where $size(f)=1$. Suppose then that there exists some other s-t path $P'$ in $G$. 

- If $\sum\{l_e : e \in P\} < \sum\{l_e : e \in P'\}$ then
	- $P$ is a shorter length s-t path in G
	- $\sum\{l_ef_e : e \in P\} < \sum\{l_ef_e : e \in P'\}$
- If $\sum\{l_e : e \in P\} > \sum\{l_e : e \in P'\}$ then
	- $P'$ is a shorter length s-t path in G
	- $\sum\{l_ef_e : e \in P\} > \sum\{l_ef_e : e \in P'\}$
- $\sum_{e \in P}l_e = \sum_{e \in P'}l_e$ then
	- $P$ and $P'$ have the same length.
	- $\sum\{l_ef_e : e \in P\} = \sum\{l_ef_e : e \in P'\}$

Therefore, the shortest s-t path in $G$ minimizes the expression $\sum_el_ef_e$.

## 7.28b Shortest Path as LP
- $\min \sum_el_ef_e$
