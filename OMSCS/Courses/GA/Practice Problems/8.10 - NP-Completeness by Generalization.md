## (c) MAX SAT
> Given a CNF formula and an integer g, find a truth assignment that satisfies at least g clauses.

Shortcutting this immensely, but we can basically just pass any CNF formula $f$ to MAX-SAT, setting $g$ to $m$, the number of clauses in $f$. This reduces all SAT variants to MAX-SAT. The proof will simply state the obvious over and over.

## (f) SET COVER.
> Given a set of sets $S$ and a set of elements $B$, find a subset of sets from $S$ whose union is $B$.

This problem was the subject of homework 10, so I don't feel the need to make a full proof here. We can convert a graph $G$ to a bipartite graph, by

1. Make a new graph $G'$
2. Convert each edge in $G$ to a vertex in $G'$. We'll call those vertices $V_E$
3. Add all the vertices of $V$ to $G'$
4. For each $v \in V$, add edges to the vertices in $V_E$, based on the edges they connected to in $G$

We can then convert this bipartite graph to the requisite sets of sets required by the Set Cover algorithm. This allows us to reduce the Vertex Cover problem to the Set Cover problem.

## (g) RELIABLE NETWORK
We are given an $n \times n$ a distance matrix $d_{ij}$, an $n \times n$ *connectivity requirement* matrix $r_{ij}$, as well as a budget $b$. We must find a graph $G=(V, E)$ where $|V|=n$ such that

1. The total cost of all edges is $b$ or less
2. between any 2 distinct vertices $i$ and $j$ there are $r_{ij}$ vertex-disjoint paths.

**Hint:** Suppose that all $d_{ij}$'s are 1 or 2, $b=n$, and all $r_{ij}$'s are 2. Which well known NP-complete problem is this?
