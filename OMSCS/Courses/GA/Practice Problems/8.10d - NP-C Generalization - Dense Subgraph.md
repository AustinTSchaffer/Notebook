# 8.10d - NP-C Generalization - Dense Subgraph
> Given a graph and two integers $a$ and $b$, find a set of $a$ vertices of $G=(V,E)$ such that there are at least $b$ edges between them.

## DS is in NP
A solution to a DS problem instance contains a set of vertices $S$. We can validate that this set of vertices is of length $a$ in $O(|V|)$ time.

Next, we need to perform this operation-

$$b \le \Big|\big(u,v\big) \in E\space:\space \big(u \in S\big) \wedge \big(v \in S\big)\Big|$$

-which runs in some polynomial-bounded time.

Therefore, DS is in NP.

## Clique $\rightarrow$ DS
The most obvious NP-Complete algorithm that can be reduced to DS is Clique. This reduction will prove that DS is in NP-Hard.
### Input Transformation
Take an instance $I=(G=(V,E),g)$ of a Clique problem, where $G$ is some undirected graph and $g$ is the target clique size. We create an instance $I'=(G',a,b)$ of a DS problem by setting:

- $G'=G$
- $a=g$
- $b=g(g-1)/2$

All of these operations are constant-time in $|I|$.

### Output Transformation
Just return $S$.
### Justification
If the Clique problem has a solution, then the DS problem as a solution. A Clique of size $g$ has $g$ vertices and $g(g-1)/2$ edges. Therefore, it satisfies the search condition for the DS problem, which is looking for a dense subgraph with $a=g$ vertices at **at least** $b=g(g-1)/2$ edges.

If the DS problem has a solution, then the Clique problem has a solution. If the DS problem has a solution, then we've found a subgraph of $G$ which has $a=g$ vertices and **at least** $b=g(g-1)/2$ edges. If you have such a subgraph, you may find that it's impossible to add any additional edges to that subgraph, as it is already fully connected. Therefore, that subgraph satisfies the requirements of being a clique of size $g$.

Therefore, the DS problem has a solution iff the Clique problem has a solution. Since we can reduce a Clique problem to a DS problem, that proves that the DS problem is in NP Hard.

## Conclusion
We have proven that the Dense Subgraph problem is in NP and is also in NP-Hard. Therefore, the Dense Subgraph problem is NP-Complete.
