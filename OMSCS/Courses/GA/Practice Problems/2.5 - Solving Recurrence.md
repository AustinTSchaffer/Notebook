# 2.5 - Solving Recurrence
Solve the following recurrence relations and give a $\Theta$ bound for each of them.

1. $T(n)=2T(n/3)+1$
2. $T(n)=5T(n/4)+n$
3. $T(n)=7T(n/7)+n$
4. $T(n)=9T(n/3)+n^2$
5. $T(n)=8T(n/2)+n^3$
6. $T(n)=49T(n/25)+n^{3/2}log \space n$
7. $T(n)=T(n-1)+2$
8. $T(n)=T(n-1)+n^c$ where $c \ge 1$ is a constant.
9. $T(n)=T(n-1)+c^n$ where $c \gt 1$ is a constant.
10. $T(n)=2T(n-1)+1$
11. $T(n)=T(\sqrt{n})+1$

## Results
1. $T(n)=2T(n/3)+1$
	- $a=2,b=3,d=0$
	- $d<log_32$
	- $T(n)=O(n^{log_32})$
2. $T(n)=5T(n/4)+n$
	- $a=5,b=4,d=1$
	- $log_45 \approx 1.16$
	- $d < log_45$
	- $T(n)=O(n^{log_45})$
3. $T(n)=7T(n/7)+n$
	- $a=7,b=7,d=1$
	- $log_77=1$
	- $d=log_77$
	- $T(n)=O(n \space log \space n)$
4. $T(n)=9T(n/3)+n^2$
	- $a=9,b=3,d=2$
	- $log_39=2$
	- $d = log_39$
	- $T(n)=O(n^2 log \space n)$
5. $T(n)=8T(n/2)+n^3$
	 - $a=8,b=2,d=3$
	 - $log_28=3$
	 - $d=log_28$
	 - $T(n)=O(n^3 log \space n)$
6. $T(n)=49T(n/25)+n^{3/2}log \space n$
	- $a=49,b=25,d>1.5$
	- $log_{25}49 \approx 1.2$
	- $d > log_{25}49$
	- $T(n)=O(n^{3/2}log \space n)$
7. $T(n)=T(n-1)+2$
	- $a=1,b=1,d=0$
	- $T(n)=O(n)$
8. $T(n)=T(n-1)+n^c$ where $c \ge 1$ is a constant.
	- $a=1,b=1,d=c$
	- if $c=1$
		- $T(n)=O(n \space log \space n)$
	- otherwise, "Any polynomial dominates any logarithm."
		- $T(n)=O(n^c)$
9. $T(n)=T(n-1)+c^n$ where $c \gt 1$ is a constant.
	- $a=1,b=1,d=?$
	- $d$ doesn't matter. "Any exponential dominates any polynomial." LHS is $O(n)$.
	- $T(n)=O(c^n)$
10. $T(n)=2T(n-1)+1$
	- $a=2,b=1,d=0$
	- Master theorem only works if $b>1$.
	- RHS doesn't matter. Can't beat $O(1)$
	- LHS, problem space decreases by 1 each time, but you need to process it twice. It's either $O(n^2)$ or $O(n^3)$.
	- $T(n)=T(n-1)+1=O(n)$, so therefore $T(n)=2T(n-1)+1$ probably equals $O(n^2)$.
11. $T(n)=T(\sqrt{n})+1$
	- $a=1,b=0.5,d=0$
	- Master theorem only works if $b>1$.
	- Problem space reduces by the log of $n$ each time. Constant time to evaluate the result.
	- $T(n)=O(log \space n)$


## 10 is Wrong
See [[2.4 - Choosing Between 3 Algorithms]].

$T(n)=2T(n-1)+1=O(2^n)$. At each depth $i$ of the call stack, you're processing $2^{i-1}$ subproblems of size $n-i+1$. The call stack has $\sim n$ depths, because that's how many depths it takes to reduce the problem to size 1 subproblems. At that depth, there are $\sim 2^n$ subproblems of size 1. Therefore, the amount of work required is $O(2^n)$, canonically one of the worst practical runtimes for a given algorithm.

## 11 is Wrong
The answer is apparently $O(log \space log \space n)$. How does that happen? We need to answer this one through substitution.

$T(n)=O(\sqrt{n})+1$
$T(\sqrt{n})=O(\sqrt{\sqrt{n}})+1$
$T(\sqrt{\sqrt{n}})=O(\sqrt{\sqrt{\sqrt{n}}})+1$

How many levels of recursion do we need in order to reach our base-case?

## 8 is Maybe Wrong?
$T(n)=T(n-1)+n^c$ where $c \ge 1$ is a constant.
- $a=1,b=1,d=c$
- if $c=1$
	- $T(n)=O(n \space log \space n)$
- otherwise, "Any polynomial dominates any logarithm."
	- $T(n)=O(n^c)$ **(Wrong?)**

In the final case, this may be testing whether we know
- From [[00.1 - Big-O Notation]]: "Higher-order polynomials dominate lower-order polynomials." 
- From [[00.3 - Exponents and Logarithms]]: $a^x \cdot a^y = a^{x+y}$

In this scenario, We are performing an $n^c$ operation $n$ times. Therefore, $T(n)=O(n \space log \space n)$ when $c=1$, but if $c > 1$, then the runtime is: $O(n*n^c)$, which equates to $O(n^{c+1})$. We can't ignore that extra $n$ term simply because $n^c$ dominates $n$... right?

Consider the case where $c=2$.
- $T(n)=T(n-1)+n^2$
- $a=1, b=1, d=2$
- The master theorem does not work here, so we either need to reason through it with a diagram or do the method from the lecture notes.


## Ignoring the Master Theorem
On the problems which can be solved by the master theorem, we can simply ignore the master theorem and attempt to solve them ourselves. For a given problem of the form $T(n) = aT(n/b)+O(n^d)$, you can iteratively replace $T(n/b^i)$ with $T(x)$ where $x=n/b^i$. You can also replace $O(n^d)$ with $cn^d$, and assert that the new equation is now an inequality: $T(n) \le aT(n/b)+cn^d$, for some $c>0$.

0. $T(n) \le aT(n/b)+cn^d$
1. Substitue $T(n/b)$ with $aT(x/b)+cx^d$, where $x=n/b$
	1. $T(n) \le a\Big[ aT((n/b)/b) + c(n/b)^d \Big] + cn^d$
	2. $= a\Big[ aT(n/b^2) + \frac{cn^d}{b^d} \Big] + cn^d$
	3. $= a^2T(n/b^2)+\frac{acn^d}{b^d} + cn^d$
	4. $= a^2T(n/b^2) + cn^d(1+\frac{a}{b^d})$
2. Substitute $T(n/b^2)$ with $aT(x/b)+cx^d$, where $x=n/b^2$
	1. $T(n) \le a^2\Big[ aT((n/b^2)/b) + c(n/b^2)^d \Big] + cn^d(1+\frac{a}{b^d})$
	2. $= a^2\Big[ aT(n/b^3) + \frac{cn^d}{b^{2d}} \Big] + cn^d(1+\frac{a}{b^d})$
	3. $= a^3 T(n/b^3) + \frac{acn^d}{b^{2d}} + cn^d(1+\frac{a}{b^d})$
	4. $= a^3 T(n/b^3) + cn^d(1+\frac{a}{b^d}+\frac{a}{b^{2d}})$
3. Substitute $T(n/b^3)$ with $aT(x/b)+cx^d$, where $x=n/b^3$ 
	1. $T(n) \le a^3 \Big[ aT((n/b^3)/b) + c(n/b^3)^d \Big] + cn^d(1+\frac{a}{b^d}+\frac{a}{b^{2d}})$
	2. $= a^3 \Big[ aT(n/b^4) + \frac{cn^d}{b^{d3}} \Big] + cn^d(1+\frac{a}{b^d}+\frac{a}{b^{2d}})$
	3. $= a^4T(n/b^4) + \frac{acn^d}{b^{d3}} + cn^d(1+\frac{a}{b^d}+\frac{a}{b^{2d}})$
	4. $= a^4T(n/b^4) + cn^d(1+\frac{a}{b^d}+\frac{a}{b^{2d}}  + \frac{a}{b^{3d}})$

By now you may notice a pattern starting to form. For a given number of iterations $i$, we get:
$$T(n) \le a^{i+1}T\left(\frac{n}{b^{i+1}}\right)+cn^d\left(1+\frac{a}{b^d} + \frac{a}{b^{2d}} + ... + \frac{a}{b^{id}} \right)$$
Now we need to analyze this runtime. Effectively, we need to compare the growth of $a^{i+1}T\left(\frac{n}{b^{i+1}}\right)$ with the growth of $cn^d\frac{a}{b^{id}}$. This is what the master theorem does. The hardest part about the Master Theorem is finding a calculator which supports arbitrary-base logarithms.

## When the Master Theorem Doesn't Work
### Problem 7
$T(n)=T(n-1)+2$

This one is pretty obvious. The problem size reduces by 1 each iteration, and there's a constant amount of work to do each iteration. This is $O(n)$.

### Problem 8
$T(n)=T(n-1)+n^c$ where $c \ge 1$ is a constant.

If $c=1$, then the result is relatively easy to calculate. 

0. $T(n)=T(n-1)+n^c$
1. $T(n)=T(n-2)+(n-1)^c+n^c$
2. $T(n) = T(n-3)+(n-2)^c+(n-1)^c+n^c$
3. $T(n)=1^c+2^c+3^c+...+(n-2)^c+(n-1)^c+n^c$

$$T(n)=O\left(\sum_{k=1}^n k^c\right)$$

The last term ($n^c$) dominates the series, but graphing $n^c$ vs $T(n)$ vs $n^{c+1}$ shows that $T(n)$ is closer to $n^{c+1}$ than it is to $n^c$. Is $n^c$ too reductive?

This is probably where the rubber meets the road WRT calculating the theoretical algorithmic complexity of a function based only on the mathematical expression of how it divides and conquers. Hopefully this isn't on the test.

For now we should simply cave in and assert:

$$O\left(\sum_{k=1}^n k^c\right)=O(n^{c+1})$$

I spent a lot of time digging around on Desmos and Wolfram, and ended up coming across some old math blogs about Power Sums, which result in crazy polynomials.

- [https://ericrowland.github.io/investigations/sumsofpowers.html](https://ericrowland.github.io/investigations/sumsofpowers.html)
- [https://mathworld.wolfram.com/PowerSum.html](https://mathworld.wolfram.com/PowerSum.html)

The polynomials generated by the expression $\sum_{k=1}^n k^c$ appear to all be of degree $c+1$. Using the magic reductive powers of big-O notation, we can collapse the result to $n^{c+1}$.

### Problem 9
$T(n)=T(n-1)+c^n$ where $c \gt 1$ is a constant.

This one is similar to the last one. The first term is a clear $O(n)$ descent, but at each layer, we perform a $c^n$ operation. In scientific terms, this algorithm is fucked. It'd be more profitable to find a way to convince your stakeholders to drop the feature request.

0. $T(n)=T(n-1)+c^n$
1. $T(n)=T(n-2)+c^{n-1}+c^n$
2. $T(n)=T(n-3)+c^{n-2}+c^{n-1}+c^n$
3. $T(n)=1+c+c^2+c^3+...+c^{n-2}+c^{n-1}+c^n$

$$T(n)=O\left(\sum_{k=0}^n c^k\right)$$

Unlike the previous problem, this is a geometric series. [[00.5 - Sequences, Series, and Sets#Geometric Series]]

$$\sum^{n}_{k=0}c^k=\frac{c^{n+1}-1}{c-1}$$

Using the magic reductive powers of big-O notation, this reduces to $O(c^n)$.

### Insights from 8 and 9
For $T(n)=T(n-1)+n^c$, the $n^c$ term dominates, but we need to account for the resulting "power sum", and take the degree of the resulting polynomial. Doing so is too much work, therefore the answer is simply $O(n^{c+1})$.

For $T(n)=T(n-1)+c^n$, the $c^n$ term dominates. The expansion results in a geometric series, which means the last term dominates without reservation, therefore the answer is simply $O(c^n)$.

As a reminder, geometric series are of the form $a + ax + ax^2 \space +...+ \space ax^n$.

### Problem 10
$T(n)=2T(n-1)+1$

This one should be fun. For clarity, we're going to substitute in some variables to make the expansion clearer.

$T(n)=aT(n-1)+c$
- $a=2$
- $c=1$

0. $T(n)=aT(n-1)+c$
1. $T(n)=a\Big[aT(n-2)+c\Big]+c$
	1. $=a^2T(n-2)+ac+c$
	2. $=a^2T(n-2)+c(1+a)$
2. $T(n)=a^2\Big[aT(n-3)+c\Big]+c(1+a)$
	1. $=a^3T(n-3)+a^2c+c(1+a)$
	2. $=a^3T(n-3)+c(1+a+a^2)$
3. $T(n)=a^3\Big[ aT(n-4)+c \Big] + c(1 + a + a^2)$
	1. $=a^4T(n-4)+a^3c+c(1+a+a^2)$
	2. $=a^4T(n-4)+c(1+a+a^2+a^3)$
4. ...
5. $T(n)=a^nT(n-n) + c(1+a+a^2+...+a^{n-1})$

This is $a^n$ plus a geometric series, where the highest term is $a^{n-1}$. Therefore the first term dominates, resulting in $T(n)=O(2^n)$.

### Problem 11
$T(n)=T(\sqrt{n})+1$

$T(n) \le T(n^b)+c$ where $b=0.5$ and $c=1$

0. $T(n) \le T(n^b)+c$
1. $T(n) \le T((n^b)^b)+c+c=T(n^{b^2})+2c$
2. $T(n) \le T((n^{b^2})^b)+c+2c=T(n^{b^3})+3c$
3. ...
4. $T(n) \le T(n^{b^i})+ic$

$$T(n)=T\left(n^{{\left(\frac{1}{2}\right)}^i}\right)+i=T\left(n^{{\frac{1}{2^i}}}\right)$$

According to some helpful folks on the forum, we now need to solve for $i$ in $n^{1/2^i} = c$ where $c=2$. This will require [[00.3 - Exponents and Logarithms]].

$$n^{\frac{1}{2^i}}=c$$
$$log_cn^{\frac{1}{2^i}}=log_cc$$
$$\frac{1}{2^i}log_cn=1$$
$$\frac{1}{2^i}=\frac{1}{log_cn}$$
$${2^i}={log_cn}$$
$$log_2{2^i}=log_2{log_cn}$$
$$i \space log_22=log_2{log_cn}$$
$$i=log_2{log_cn}$$
Therefore
$$T(n)=O(log \space log \space n)$$

Probably easier to memorize that $T(\sqrt{n})+1=O(log\space log \space n)$.
