# 8.2 - Search vs Decision
> Suppose you have a procedure which runs in polynomial time and tells you whether or not a graph has a Rudrata path. Show that you can use it to develop a polynomial-time algorithm for RUDRATA PATH (which returns the actual path, if it exists).

A Rudrata path is the same as a Hamiltonian cycle, minus one edge. This course and texbook prefers the term Rudrata, because William Rowan Hamilton wasn't even close to being the first person to discover this problem. [Rudrata](https://en.wikipedia.org/wiki/Rudrata) wrote about this problem in the 9th century, specifically referring to a knight's-tour problem.

To formalize this problem, we have an algorithm "Has Rudrata Path?", symbolized **HRP**, which runs on some graph $G$. **HRP** returns True if the graph has a Rudrata Path, and False otherwise. The implementation of this algorithm is not known, but it runs in polynomial time.

We want to use this algorithm to craft a new algorithm "Rudrata Path" (**RP**), which returns the actual Rudrata Path from some graph G.

To accomplish this, we need to filter edges from G until we have a subset of G which is a Rudrata Path in G. We first copy G, creating $G'$ which we can freely modify. For each edge $e \in E$, we can remove $e$ from $E'$, and then run $HRP$ on $G'$.
- If $HRP(G')=F$, then we need to add $e$ back to $E'$.
- If $HRP(G')=T$, then there still exists a Rudrata Path in $G'$ despite removing $e$ from $E'$.

At the end, we have $G'$, which is a copy of $G$ which may have some edges removed.
- If $HRP(G')=F$, then we can presume that $G$ has no Rudrata Path, and that $G'=G$
- If $HRP(G')=T$, then $G'$ represents a valid Rudrata Path in $G$.

In the worst case, this algorithm requires $|E|$ iterations. In each iteration, we have to remove an edge from $G'$, which requires $O(n)$ time. We also need to run $HRP$, which is a polynomial time algorithm. All of these steps are polynomial in the size of $G$, so therefore, the overall runtime is also polynomial.
