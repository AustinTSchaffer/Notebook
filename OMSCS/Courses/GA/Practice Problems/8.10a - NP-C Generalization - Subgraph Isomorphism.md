# 8.10a - NP-C Generalization - Subgraph Isomorphism
> Given as input two undirected graphs G and H, determine whether G is a subgraph of H (that is, whether by deleting certain vertices and edges of H we obtain a graph that is, up to renaming of vertices, identical to G), and if so, return the corresponding mapping of V(G) into V(H).

## SubgIso is in NP
To validate a solution to **SubgIso**, we must validate that the mapping from subgraph $G$ to supergraph $H$. This is given as a mapping from each vertex $u_G \in V_G$ to a subset of vertices $u_H \in V_H$. For each edge $(u_G, v_G) \in E_G$, we must use the output of **SubgIso** to map the 2 vertices in this edge to the corresponding edge $(u_H, v_H)$ in supergraph $H$, and validate that this edge exists in $E_H$.

A naive implementation of this procedure looks like this:
- We presume that $|V_G| \le |V_H|$, otherwise $G$ cannot be a subgraph of $H$. This is nonetheless checkable in $O(|V_G|+|V_H|)$ time.
- Iterate over all edges in $(u_G,v_G) \in E_G$: $O(|V_G|+|E_G|)$
- Map the vertices $u_G, v_G \in V_G$ of each edge in $G$ to the corresponding vertices $u_H,v_H \in V_H$: $O(|V_G|)$
- Validate the following.
	- $u_H \in V_H$
	- $v_H \in V_H$
	- $(u_H, v_H) \in E_H$
	- This has time complexity: $O(|V_H|)+O(|V_H|)+O(|E_H|)$

 Therefore, the overall runtime is $O\Big(\big(|V_G|+|E_G|\big)\big(|V_H|+|E_H|\big)\Big)$, which is polynomial in the input size. Therefore, **SubgIso** is in NP.

## SubgIso is in NP-Complete
To prove that **SubgIso** is in NP-Complete, we will be performing a reduction from Clique which is known to be NP-Complete.

### Input Transformation
An instance $I$ of a Clique problem consists of a graph $G=(V,E)$ and a goal clique size of $g$. From these parameters, we create a clique of size $g$, called $G'=(V',E')$. This is accomplished by creating a set of vertices $V'$ where $|V'|=g$ and by creating a set of edges $E'$ between all pairs of vertices in $V'$.

We can then run **SubgIso** on $I'=(G',G)$, to check whether $G'$ is a subgraph of $G$. 

If $I$ has a solution $S$, then $g \le |V|$ must hold, therefore this process requires $O(n^2)$ time, which is polynomial in $|I|$.

### Output Transformation
If there is no solution to $I'$, then we return NO, as there's no solution to $I$. If there is a solution to $I'$, it consists of a mapping $M(v')=v$ where $v' \in V'$ and $v \in V$. We can apply this mapping to all $v' \in V'$ and $e' \in E'$, to produce:
$$C=\bigg(\Big(M(v') : v' \in V'\Big), \Big(\big(M(u'), M(v')\big) : \big(u',v'\big) \in E' \Big)\bigg)$$
$C$ now represents a clique of size $g$ in $G$, which we return as the solution to $I$.

This process has the same time complexity as the process required to validate a solution to **SubgIso**, which is polynomial in $I'$.

### Justification
A $g$-Clique of $G$ is a subgraph of $G$ of size $g$ where all of the vertices in the subgraph are fully-connected with each other. Therefore, we can use **SubgIso** to show that such a clique exists in $G$.

- If there exists a $g$-Clique in $G$, then there must exist a subgraph of $G$ that has $g$ full-connected vertices . This proves the forward implication.
- If there does not exist a subgraph of $G$ that has $g$ fully-connected vertices, then there does not exist a $g$-Clique in $G$. This proves the contrapositive of the forward implication.

Therefore, there exists a solution to $g$-Clique iff there exists a solution to **SubgIso**. There is not much more to say about this. The **SubgIso** problem has been shown to be a more general case problem than the Clique problem, and therefore is strictly harder than Clique. 

- **SubgIso** has been shown to be in NP
- The Clique problem can be reduced to **SubgIso**
- The Clique problem has been shown to be NP-Complete

Therefore, **SubgIso** must be NP-Complete.

## Notes from TA Solution

- The solution to Clique only requires a set of vertices, not a full graph. The full graph is redundant, since it can be extracted from $G$. We can therefore omit the edge translation.
- The TA solution also mentions $g \le |V|$ as part of the input transformation runtime.
- The TA solution refers to $M(v)$ as $\pi(v)$
