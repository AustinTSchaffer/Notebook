# 8.6 - 3SAT remains NP Complete...
> On page 266 we saw that 3SAT remains NP-complete even when restricted to formulas in which each literal appears at most twice.
> 
> (a) Show that if each literal appears at most once, then the problem is solvable in polynomial time.
> 
> (b) Show that Independent Set (IS) remains NP-complete even in the special case when all the nodes in the graph have degree at most 4.

## 8.6a - P-Time Restricted 3SAT
If each literal appears at most once in a 3SAT instance, then each variable $x$ appears in 1 or 2 clauses. If variable $x$ only appears in one clause, then we can set $x$ appropriately and then remove that clause from $f$. We will be left with a problem where only the variables which have both its positive and negative literals appearing in separate clauses. From here, it's still possible to construct satisfiable $f$ and unsatisfiable $f$.

- $f_{sat,1}=(a \vee b)(\overline{a} \vee \overline{b})$
- $f_{sat,2}=(a \vee \overline{b})(\overline{a} \vee b)$
- $f_{sat,3}=(a \vee b \vee c)(\overline{a} \vee \overline{b} \vee \overline{c})$
- $f_{sat,4}=(a \vee x_1 \vee x_2)(b \vee \overline{x_1} \vee x_3)(c \vee \overline{x_2} \vee \overline{x_3})(\overline{a} \vee \overline{b} \vee \overline{c})$
- $f_{sat,5}=(a \vee b \vee c)(\overline{a})(\overline{b})$
- $f_{unsat,1}=(a)(\overline{a})$
- $f_{unsat,2}=(a)(b)(\overline{a} \vee \overline{b})$
- $f_{unsat,3}=(a)(b)(c)(\overline{a} \vee \overline{b} \vee \overline{c})$
- $f_{unsat,4}=(a \vee x_1)(b)(c)(\overline{a} \vee \overline{b} \vee \overline{c})(\overline{x_1})$

We can solve an instance of this variant of 3SAT with the following procedure:

- Create a priority queue of the clauses in $f$ based on the number of literals in each clause. This PQ should yield smaller clauses first.
- Repeat this procedure until $f$ has no remaining clauses.
	- Take clause $c_1$ from the PQ.
	- Look at the first literal $x$ in $c_1$ and set variable $x$ such that $c$ is now satisfied.
	- Remove $c_1$ from $f$.
	- Find the clause $c_2$ which contains $\overline{x}$.
		- If it exists:
			- Remove $\overline{x}$ from $c_2$.
			- If $c_2$ is now empty, then $f$ is unsatisfiable.
		- Otherwise, update the priority of $c_2$ in the PQ.

There are certainly more efficient methods of going about this procedure, but all of these steps are polynomial in the size of $f$. Let's look at $f_{sat,4}$ as an example.

- $f_{sat,4}=(a \vee x_1 \vee x_2)(b \vee \overline{x_1} \vee x_3)(c \vee \overline{x_2} \vee \overline{x_3})(\overline{a} \vee \overline{b} \vee \overline{c})$
	- Set $a=T$
	- Remove $(a \vee x_1 \vee x_2)$
	- Remove $\overline{a}$ from $(\overline{a} \vee \overline{b} \vee \overline{c})$
- $f_{sat,4}=(\overline{b} \vee \overline{c})(b \vee \overline{x_1} \vee x_3)(c \vee \overline{x_2} \vee \overline{x_3})$
	- Set $\overline{b}=T$
	- Remove $(\overline{b} \vee \overline{c})$
	- Remove $\overline{\overline{b}}$ from $(b \vee \overline{x_1} \vee x_3)$
- $f_{sat,4}=(\overline{x_1} \vee x_3)(c \vee \overline{x_2} \vee \overline{x_3})$
	- Set $\overline{x_1}=T$
	- Remove $(\overline{x_1} \vee x_3)$
	- $x_1$ appears in no other clauses.
- $f_{sat,4}=(c \vee \overline{x_2} \vee \overline{x_3})$
	- Set $c=T$
- $x_2$ and $x_3$ were unset, and can therefore hold any value.

The difference between this problem and standard 3SAT is the restriction on how often each literal can appear. This causes $f$ to form groups of "connected components" which can be processed in a logical order, in order to find a satisfying assignment to $f$, or show that $f$ is unsatisfiable.

## 8.6a - Restricted 3SAT -> Max Flow
> There are certainly more efficient methods of going about this procedure.

Regarding this comment, we can also reframe the problem as a max-flow problem. This idea comes from **George Kudrayvtsev** (george.k@gatech.edu).

- Each variable becomes a node.
- Each clause becomes a node.
- Each variable node connects the clause nodes in which it appears.
- Add a source, which connects to all variable nodes.
- Add a sink, which connects from all clause nodes.
- All edges have capacity 1.

The max flow in this network is $\le m$, where $m$ is the number of clauses. Therefore, the time complexity of Ford-Fulkerson is polynomial in the size of the problem. From the resulting $flow[]$, we can determine an assignment for each variable by seeing which edges were used.

From this reduction, and the earlier examples, we conjecture that $f$ has a satisfying assignment iff $n \ge m$, where $n$ is the number of variables.

## 8.6b - Restricted Independent Set
The reduction from 3SAT to IS involves creating a graph from $f$ and then finding an independent set within that graph. The construction of this graph occurs thusly:

- For each clause, add the literals of the clause to the graph, and connect them as a 3-Clique.
- For each literal, connect the literal to the opposite literal in all other clauses. e.g. $x$ will be connected to all $\overline{x}$. All $\overline{x}$ will be connected to all $x$.

We then find an IS of size $m$ for this graph, where $m$ is the number of clauses in $f$. The result of this can be converted to a solution for the original 3SAT problem.

We have shown that a 3SAT instance where each literal appears at most twice is NP-Complete. If we construct the corresponding implication graph from such a problem, then each node will have AT MOST 4 edges. From each literal node, there will be exactly 2 edges between that node and the other 2 nodes which exist in the same clause. There will also be at most 2 additional edges which connect that literal to its corresponding opposite literals in other clauses.

Therefore, we can reduce 3SAT-2LIT to IS-DEG4, making IS-DEG4 NP-Hard. The proof of IS-DEG4 being in NP is self-evident due to IS being in NP. Therefore, IS-DEG4 is NP-Complete.
