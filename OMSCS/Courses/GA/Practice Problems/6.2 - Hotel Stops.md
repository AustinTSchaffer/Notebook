# 6.2 - Hotel Stops
![[6.2 - Hotel Stops - 1.png]]
![[6.2 - Hotel Stops - 2.png]]

- Input: A list of numbers $A$
- Output: The subsequence of $A$ which minimizes the total penalty.

## Step 1: Define the Subproblem in Words
```
Given a list of hotels "A" of length n
for i=1 -> n
P(i) = the minimum penalty subsequence in a_1, ..., a_i which includes a_i
```

## Example
$A=\{50, 75, 199, 201, 202, 399, 400, 401, 500, 550, 570, 900\}$

- $i=1$
	- $A=\{50\}$
	- You have to stop at 50.
	- $P(1)=(200-50)^2=22,500$
- $i=2$
	- $A=\{50, 75\}$
	- You can skip 50.
	- You have to stop at 75.
	- $P(2)=(200-75)^2=15,625$
- $i=3$
	- $A=\{50,75,199\}$
	- You can skip 50 and 75.
	- You have to stop at 199.
	- $P(3)=(200-199)^2$
	- $P(3)=1$
- $i=4$
	- $A=\{50,75,199,201\}$
	- You can skip the prefix.
	- You have to stop at $A_4$
	- If you reuse $P(3)$, you'll end up with
		- $P(4)=(200-(201-199))^2+P(3)$
		- $P(4)=198^2+1$
	- If you don't use $P(3)$, you'll end up with
		- $P(4)=(200-201)^2=1$
	- $P(4)=1$
- $i=5$
	- $A=\{50,75,199,201,202\}$
	- You have to stop at $A_5$
	- Starting position and additional penalty.
		- $0:$
			- $0+(200-202)^2$
			- $4$
		- $50:$
			- $P(1)+(200-(202-50))^2$
			- $22,500+2,304$
			- $24,804$
		- $75:$
			- $P(2)+(200-(202-75))^2$
			- $15,625+5,329$
			- $20,954$
		- $199:$
			- $P(3)+(200-(202-199))^2$
			- $1+38,809$
			- $38,810$
		- $201:$
			- $P(4)+(200-(202-201))^2$
			- $1+39,601$
			- $39,602$
	- $P(4)=4$

So for each hotel $A_i$, you need to calculate the penalty of stopping at that hotel from the beginning of the journey, with no stops. This is $(200-A_i)^2$ You also need to find the penalty for stopping at that hotel from each hotel already seen on the journey, including the penalty of stopping at that previous hotel. Those calculations are given by $P(j)+(200-(A_i-A_j))^2$. This will result in a list of $i+1$ penalties, from which you need to take the minimum.

## Step 2: Define the Recurrence Relation
- This problem seems similar to LIS.
- Is there a risk with using a greedy algorithm? You want to travel exactly 200 miles in a day. Sometimes it might be worth stopping early for a larger penalty to avoid a bigger penalty later. Does the math check out? The penalty is the distance squared.
- Making the algorithm $n^2$ seems to account for possible greediness.

$P(i)=min\bigg\{(200-A_i)^2,min\space\Big\{P(j)+\big(200-A_i+A_j\big)^2:0 \le j \lt i\Big\}\bigg\}$

## Code
```python
def hotel_stops(A):
    # Start by calculating the one-leg trip penalties.
    penalties = [(200 - a) ** 2 for a in A]

    # Keep track of the index of the hotel that was stopped
    # at prior to stopping at A_i. -1 indicates mile-marker 0,
    # i.e. the start of the trip. This is an implementation
    # detail. We should initialize this to 0 if `A[0] == 0`,
    # though that would affect the impl. of the next part.
    prior_hotel_indexes = [-1 for _ in A]

    # Determine the minimum penalty that can be incurred if you
    # stop at A_i
    for i in range(len(A)):
        for j in range(i):
            p = penalties[j] + ((200 - (A[i] - A[j])) ** 2)
            if p < penalties[i]:
                penalties[i] = p
                prior_hotel_indexes[i] = j

    # Reconstruct the route.
    hotel_indexes = [len(A) - 1]
    while hotel_indexes[0] != -1:
        hotel_indexes.insert(0, prior_hotel_indexes[hotel_indexes[0]])

	# If we just want the hotel indexes:
	return penalties[len(A) - 1], hotel_indexes
	
	# If we want the mile markers of the hotels:
    return penalties[len(A) - 1], [
        (0 if h_idx == -1 else A[h_idx]) for h_idx in hotel_indexes
    ]    
```
