# 2.15 - Split In-Place
![[Pasted image 20260207104745.png]]

When the problem says "without allocating new memory", it likely means without allocating new arrays. It'd probably be impossible to solve this without allocating at least some constant amount of memory within the current stack-frame, to hold a few integers.

Given an unsorted $S$ and some $v$, we can partition $S$ into $S_{<v}$, $S_{=v}$, and $S_{>v}$ by first determining the sizes of those sub-arrays $|S_{<v}|$, $|S_{=v}|$, and $|S_{>v}|$. This can be performed in linear time by iterating over $S$ and counting the values satisfying each subscript condition. You don't actually need to initialize all three, since you can get one by subtracting the others from known information (e.g. $|S_{=v}|=|S|-|S_{<v}|-|S_{>v}|$).

- $S=[2,2,2,4,4,3,3,1,4,1,1]$
- $v=3$
- $|S_{<v}|=6$
- $|S_{=v}|=2$
- $|S_{>v}|=3$

Now that we have the subarray sizes, we can iterate over $S$ again, knowing where to put each element. We have to introduce 3 new variables, each initialized to 0, which track the number of elements which have been correctly placed. As we'll see in the example code, you don't actually need $P_{<v}$.

- $P_{<v}:=0$
- $P_{=v}:=0$
- $P_{>v}:=0$

Using these tracking variables, we can iterate over $S$ again to swap elements into the spaces they belong. At each position $1 \le i \le (|S_{<v}| + |S_{=v}|)$ in $S$, we check to see if $s_i$ is correctly placed. Once the values of $S$ are correctly partitioned into $S_{<v}$ and $S_{=v}$, by deduction, we can infer that all of the elements in $S_{>v}$ are also correctly placed.

$\text{correctly\_placed}(i)=$
- $\Big((S[i]<v) \wedge (i \le |S_{<v}|)\Big)$
- $\vee \Big((S[i] = v) \wedge (|S_{<v}| < i \le (|S_{<v}| + |S_{=v}| )\Big)$
- $\vee \Big((S[i]>v) \wedge ((|S_{<v}| + |S_{=v}|) < i \le |S|) \Big)$ (this case is never reached)

Now that we've defined whether an element at $i$ is correctly placed, we can swap elements based on the known sizes of each partition, and the known information about which elements are correctly placed. This is not a D&C algorithm, but it enables D&C algorithms and has O(n) time complexity, which is the minimum for this kind of problem. At the minimum, you need to validate that $S$ is already correctly partitioned, which cannot be done faster than $O(n)$.

```python
def inplace_partition(S, v):
	# Subarray sizes
	S_lt = 0
	S_eq = 0
	
	for i in range(len(S)):
		if S[i] < v:
			S_lt += 1
		elif S[i] == v:
			S_eq += 1

	# Correctly placed markers.
	P_eq = 0
	P_gt = 0
	
	i = 0
	while i < (S_lt + S_eq):
		if (S[i] < v) and (i < S_lt):
			# S[i] is correctly placed in S_lt
			i += 1

		elif (S[i] == v) and (S_lt <= i < (S_lt + S_eq)):
			# S[i] is correctly placed in S_eq
			P_eq += 1
			i += 1

		elif S[i] == v:
			# Swap S[i] to the S_eq partition
			t = S[i]
			S[i] = S[S_lt + P_eq]
			S[S_lt + P_eq] = t
			P_eq += 1

		elif S[i] > v:
			# Swap S[i] to the S_gt partition
			t = S[i]
			S[i] = S[S_lt + S_eq + P_gt]
			S[S_lt + S_eq + P_gt] = t
			P_gt += 1
```
