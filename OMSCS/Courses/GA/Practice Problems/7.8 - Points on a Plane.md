# 7.8 - Points on a Plane
You are given the following points in the plane:

$$(1,3), (2,5), (3,7), (5,11), (7,14), (8,15), (10,19)$$

You want to find a line $ax+by=c$ that approximately passes through these points (no line is a perfect fit). Write a linear program (you don’t need to solve it) to find the line that minimizes the maximum absolute error:

$$\max_{1 \le i \le 7} | ax_i + by_i−c|$$

## Fixing Definition of Line
We note that this problem doesn't require that we generalize the solution to all possible collections of points. It's clear geometrically that this collection of points can be defined by a linear regression with a positive slope. i.e. the given points are all "up and to the right" (UATTR). We can calculate the regression for these points with standard tools, giving us:

$$y=1.74145x+1.61538$$

This regression has a positive slope and passes through the y-axis above zero. Remember that the definition of "the line" we're searching for is $ax+by=c$. Therefore,

- $c$ will be positive.
- Either $a$ or $b$ must be negative, but not both.

Unfortunately, standard-form LPs don't allow for negative decision variables. In my mind, the most sensible option here would be to pretend that the definition of our target model is actually $-ax+by=c$, proceed with $a$ as a positive value, then invert $a$ in order to hand the results back to the stakeholders.

## Fixing Absolute Error Calculation
We also need to adjust the absolute error calculation. If we set $a,b,c=[0,0,0]$, we get a "max absolute error" of $0$. For each $x_i,y_i$, we can instead define error as: $|y_i-(\frac{a}{b}x_i+\frac{c}{b})|$.

This gives us the following optimization $\min \max$ over these error terms:

- $|3 - (\frac{a}{b}1+\frac{c}{b})|$
- $|5 - (\frac{a}{b}2+\frac{c}{b})|$
- $|7 - (\frac{a}{b}3+\frac{c}{b})|$
- $|11 - (\frac{a}{b}5+\frac{c}{b})|$
- $|14 - (\frac{a}{b}7+\frac{c}{b})|$
- $|15 - (\frac{a}{b}8+\frac{c}{b})|$
- $|19 - (\frac{a}{b}10+\frac{c}{b})|$

Where $a$, $b$, and $c$ are our decision variables.

## Completing the LP
In order to optimize the "minimum maximum absolute error" for this problem, we need to define an error term. For this, we will use $e$. $e$ becomes the "variable" we're trying to optimize, though $e$ will depend entirely on the values of $a$, $b$, and $c$ in conjunction with our data.

This variable will be equal to the maximum error over all the error terms above. This can be accomplished by marking each error term as being $\le e$.

- $|3 - (\frac{a}{b}1+\frac{c}{b})| \le e$
- $|5 - (\frac{a}{b}2+\frac{c}{b})| \le e$
- $|7 - (\frac{a}{b}3+\frac{c}{b})| \le e$
- $|11 - (\frac{a}{b}5+\frac{c}{b})| \le e$
- $|14 - (\frac{a}{b}7+\frac{c}{b})| \le e$
- $|15 - (\frac{a}{b}8+\frac{c}{b})| \le e$
- $|19 - (\frac{a}{b}10+\frac{c}{b})| \le e$

Searching for $min(e)$ (or $max(-e)$) will put downward pressure on the error terms through the manipulation of $a$, $b$, and $c$.

To further convert these terms into standard form, we need to drop the absolute value calculation. This can be done by ensuring that both the positive value and the negative value from each term are both $\le e$.

- $+(3 - (\frac{a}{b}1+\frac{c}{b})) \le e$
- $+(5 - (\frac{a}{b}2+\frac{c}{b})) \le e$
- $+(7 - (\frac{a}{b}3+\frac{c}{b})) \le e$
- $+(11 - (\frac{a}{b}5+\frac{c}{b})) \le e$
- $+(14 - (\frac{a}{b}7+\frac{c}{b})) \le e$
- $+(15 - (\frac{a}{b}8+\frac{c}{b})) \le e$
- $+(19 - (\frac{a}{b}10+\frac{c}{b})) \le e$
- $-(3 - (\frac{a}{b}1+\frac{c}{b})) \le e$
- $-(5 - (\frac{a}{b}2+\frac{c}{b})) \le e$
- $-(7 - (\frac{a}{b}3+\frac{c}{b})) \le e$
- $-(11 - (\frac{a}{b}5+\frac{c}{b})) \le e$
- $-(14 - (\frac{a}{b}7+\frac{c}{b})) \le e$
- $-(15 - (\frac{a}{b}8+\frac{c}{b})) \le e$
- $-(19 - (\frac{a}{b}10+\frac{c}{b})) \le e$

This is good enough for a solvable formulation of this LP. However, in the context of this course, we still aren't where we need to be. First, all 4 of the decision variables must be on the LHS. This can be accomplished by subtracting $e$ from both sides. We also need to "un-simplify", ensuring that each variable is independent from each other, allowing the constraints to be specified by an $m \times n$ matrix.

Let's first unpack all of the parentheses and distribute the negatives accordingly.

- $3 - \frac{a}{b}1-\frac{c}{b} - e \le 0$
- $5 - \frac{a}{b}2-\frac{c}{b} - e \le 0$
- $7 - \frac{a}{b}3-\frac{c}{b} - e \le 0$
- $11 - \frac{a}{b}5-\frac{c}{b} - e \le 0$
- $14 - \frac{a}{b}7-\frac{c}{b} - e \le 0$
- $15 - \frac{a}{b}8-\frac{c}{b} - e \le 0$
- $19 - \frac{a}{b}10-\frac{c}{b} - e \le 0$
- $-3 + \frac{a}{b}1+\frac{c}{b} - e \le 0$
- $-5 + \frac{a}{b}2+\frac{c}{b} - e \le 0$
- $-7 + \frac{a}{b}3+\frac{c}{b} - e \le 0$
- $-11 + \frac{a}{b}5+\frac{c}{b} - e \le 0$
- $-14 + \frac{a}{b}7+\frac{c}{b} - e \le 0$
- $-15 + \frac{a}{b}8+\frac{c}{b} - e \le 0$
- $-19 + \frac{a}{b}10+\frac{c}{b} - e \le 0$

Now, we're no longer in a format that can be solved using LP tools. We have a system of inequalities that cannot be expressed through linear algebra, assuming that $a$, $b$, $c$, and $e$ are all decision variables. However, we note that we only need 2 variables to define a 2D linear regression:

$$y=mx+b$$

Therefore, we have too many variables for the actual problem. We can "anchor" $b$ to $1$ by removing it from the problem.

- $3 - 1a - c - e \le 0$
- $5 - 2a - c - e \le 0$
- $7 - 3a - c - e \le 0$
- $11 - 5a - c - e \le 0$
- $14 - 7a - c - e \le 0$
- $15 - 8a - c - e \le 0$
- $19 - 10a - c - e \le 0$
- $-3 + 1a + c - e \le 0$
- $-5 + 2a + c - e \le 0$
- $-7 + 3a + c - e \le 0$
- $-11 + 5a + c - e \le 0$
- $-14 + 7a + c - e \le 0$
- $-15 + 8a + c - e \le 0$
- $-19 + 10a + c - e \le 0$

If we then move the constant terms to the other side of the inequality, we have completed our conversion to standard form.

- $-1a - c - e \le -3$
- $-2a - c - e \le -5$
- $-3a - c - e \le -7$
- $-5a - c - e \le -11$
- $-7a - c - e \le -14$
- $-8a - c - e \le -15$
- $-10a - c - e \le -19$
- $1a + c - e \le 3$
- $2a + c - e \le 5$
- $3a + c - e \le 7$
- $5a + c - e \le 11$
- $7a + c - e \le 14$
- $8a + c - e \le 15$
- $10a + c - e \le 19$

## LP in Standard Form

- Objective $\max(-e)$
- s.t.
	- $a, c, e \ge 0$
    - $-1a - c - e \le -3$
    - $-2a - c - e \le -5$
    - $-3a - c - e \le -7$
    - $-5a - c - e \le -11$
    - $-7a - c - e \le -14$
    - $-8a - c - e \le -15$
    - $-10a - c - e \le -19$
    - $1a + c - e \le 3$
    - $2a + c - e \le 5$
    - $3a + c - e \le 7$
    - $5a + c - e \le 11$
    - $7a + c - e \le 14$
    - $8a + c - e \le 15$
    - $10a + c - e \le 19$
