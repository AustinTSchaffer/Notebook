# 06.3 - NP - 3SAT
> 3SAT is NP-Complete

- Cook-Levin Theorem ('71)
- They independently proved that SAT is NP-complete.
- Karp '72: Showed 21 other problems are NP-complete

## 3SAT
- **Input**
	- Boolean formula $f$ in CNF
	- $n$ variables and $m$ clauses
	- each clause as $\le 3$ literals
- **Output**
	- Satisfying assignment, if one exists
	- 'NO' otherwise
- **Proof Outline**
	- 3SAT $\in NP$
	- $SAT \rightarrow 3SAT$
	- thus: for all $A \in NP : A \rightarrow 3SAT$

### 3SAT $\in NP$
- Given 3SAT input $f$ and T/F assignment for $x_1,...,x_n$
- For each clause $c \in f$
	- in $O(1)$ time can check that at least one literal in $c$ is satisfied.
	- $O(1)$ because there are at most 3 literals in $c$
- If $\forall_{c \in f} sat(c)$, then $f$ is satisfied
- $O(m)$ total time.

### $SAT \rightarrow 3SAT$
- Take input $f$ for SAT
- We need to translate the input for the SAT problem and transform it into an input to the 3SAT problem ($f'$).
- Some of the clauses in a SAT $f$ might have more than 3 literals.
- This produces $\sigma'$.
- We then need to transform satisfying $\sigma'$ for $f'$ to $\sigma$ for $f$.
- If there does not exist a $\sigma'$ for $f'$, then there exists no satisfying assignment for $f$.
- $\sigma'$ satisfies $f'$ $\iff$ $\sigma$ satisfies $f$

## Example Reduction
- Sample SAT input: $f=(x_3) \wedge (\overline{x_2} \vee x_3 \vee \overline{x_1} \vee \overline{x_4}) \wedge (x_2 \vee x_1)$
	- $c_1=x_3$
	- $c_2=\overline{x_2} \vee x_3 \vee \overline{x_1} \vee \overline{x_4}$
	- $c_3=x_2 \vee x_1$
- $c_1$ and $c_3$ can be unchanged, we need a procedure to translate $c:|c|>3$.
- For $c_2$
	- we can create a new variable $y$
	- $c'_2=(\overline{x_2} \vee x_3 \vee y) \wedge (\overline{y} \vee \overline{x_1} \vee \overline{x_4})$
	- The claim is that $sat(c_2) \iff sat(c'_2)$

### Proof of Claim
- $c_2=\overline{x_2} \vee x_3 \vee \overline{x_1} \vee \overline{x_4}$
- $c'_2=(\overline{x_2} \vee x_3 \vee y) \wedge (\overline{y} \vee \overline{x_1} \vee \overline{x_4})$
- **Claim:** $sat(c_2) \iff sat(c'_2)$
### Forward Claim
- Take satisfying assignment for $c_2$. One of these must be an assignment in the broader problem.
	- $x_2=F$
	- $x_3=T$
	- $x_1=F$
	- $x_4=F$
- Generate a satisfying assignment for $c'_2$
	- If $x_2=F$ or $x_3=T$, then set $y=F$.
	- This ensures the 2nd subclause in $c'_2$ is satisfied.
	- If $x_1=F$ or $x_4=F$, then set $y=T$. 
	- This ensures the 1st subclause in $c'_2$ is satisfied.

### Reverse Claim
- Take satisfying assignment for $c'_2$.
- if $y=T$,
	- the first subclause in $c'_2$ is satisfied. We can use the worst case for $c_2$ and presume $\overline{x_2}$ and $x_3$ to be unsatisfied. ($x_2=T$ and $x_3=F$)
	- To satisfy the 2nd subclause: $x_1=F$ or $x_4=F$
	- In either case for the 2nd subclause: $c_2$ is satisfied.
- if $y=F$,
	- The second subclause in $c'_2$ is satisfied. We can use the worst case for $c_2$ and presume $x_1=T$ and $x_4=T$
	- To satisfy the first subclause: $x_2=F$ or $x_3=T$
	- In either case for the 1st subclause: $c_2$ is satisfied.
- For every satisfying assignment for $c_2'$, if we ignore $y$, then we have a satisfying assignment for $c_2$.

## Big Clauses
- Consider a CNF clause of arbitrary length $k$
- $C=(a_1 \vee a_2 \vee ... \vee a_k)$ where $a_1, a_2, ..., a_k$ are literals
- Create $k-3$ new variables: $y_1, y_2, ..., y_{k-3}$
- Replace $C$ by $k-2$ clauses:
- $C'=c'_1 \wedge c'_2 \wedge ... \wedge c'_{k-2}$
	- $c'_1=(a_1 \vee a_2 \vee y_1)$
	- $c'_2=(\overline{y_1} \vee a_3 \vee y_2)$
	- $c'_3 = (\overline{y_2} \vee a_4 \vee y_3)$
	- $...$
	- $c'_{k-3}=(\overline{y_{k-4}} \vee a_{k-2} \vee y_{k-3})$
	- $c'_{k-2}=(\overline{y_{k-3}} \vee a_{k-1} \vee a_k)$
- Each new $y$ variable "links" pairs of subclauses in  $C'$ together. This is achieved by having $y_i$ in one subclause and $\overline{y_i}$ in the next subclause.
- The first and last subclause of $C'$ each contain 2 of the literals from $C$
- Each interior subclause of $C'$ has space for only one literal from $C$

### General Claim: Forward
- Take assignment to $a_1,...,a_k$ satisfying $C$, one of these literals must be satisfied.
- Let $a_i$ be min $i$ where $a_i$ is satisfied.
- Since $a_i=T$, the $(i-1)$-st clause of $C'$ is satisfied.
	- Set $y_1=y_2=...=y_{i-2}=T$ to satisfy the first $(i-2)$ subclauses in $C'$
	- Set $y_{i-1}=y_i=...=y_{k-2}=F$ to satisfy the remaining clauses.
- We only need one literal of $C$ of the satisfied, and we can use that literal to satisfy all subclauses of $C'$.
- Remember that $C$ is the "harder" problem, and we're trying to reduce $C$ to $C'$
- "This proves that if we have a solution to $C$, then we have a solution to $C'$".
- This is the positive of $A \rightarrow B$

### General Claim: Reverse
- Suppose that $a_1=a_2=...=a_k=F$
- From $C'$
	- With subclause 1, $y_1$ must be $T$.
	- With subclause 2, $y_2$ must be $T$.
	- ...
	- For subclause $(k-3)$, $y_{k-3}=T$
	- For subclause $(k-2)$,
		- $\overline{y_{k-3}}$ is not satisfied
		- $a_{k-1}$ is not satisfied
		- $a_{k}$ is not satisfied
		- This subclause of $C'$ is not satisfied.
- Therefore, $C'$ is not satisfied.
- "This proves that if we have NO solution to $C$, then we have NO solution to $C'$."
- This is the contrapositive of $B \rightarrow A$

## SAT $\rightarrow$ 3SAT
- Consider $f$ for SAT
- Create input $f'$ for 3SAT
	- For each clause $C \in f$
		- if $|C|\le3$, then add $C$ to $f'$
		- if $|C| \gt 3$, then
			- create $|C|-3$ new variables
			- create $C'$ as defined before
- $f$ is satisfiable $\iff$ $f'$ is satisfiable

## 3SAT Correctness
- Given assignment to $x_1,...,x_n$ satisfying $f$. For clause $C_i \in f$, there is an assignment to $k-3$ new variables which are unique to the transformation $C_i \rightarrow C'_i$. These new variables are not used in any other $C_j \in f : i \ne j$.
- Given satisfying assignment for $f'$, for $C' \in f$, $\ge 1$ literal in $C$ is satisfied.
- $\therefore$ $f$ is satisfiable $\iff$ $f'$ is satisfiable

Given satisfying assignment $\sigma'$ for $f'$, how do we produce satisfying assignment $\sigma$ for $f$? Easy, ignore the assignments for the new variables. These do not affect the satisfiability of the original variables in $f$.

$f$ has $n$ variables and $m$ clauses. $f'$ has $O(nm)$ variables and $O(nm)$ clauses. These are polynomial in the size of $f$.
