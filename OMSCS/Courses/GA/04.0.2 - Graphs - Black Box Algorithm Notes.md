# 04.0.1 - Graphs - Black Box Algorithm Notes
These are assorted notes based on [[04.0.1 - Graphs - Black Box Algorithms]], to help with studying the algorithms for this course.

## Max Flow Algorithms
Both **Ford-Fulkerson (FF)** and **Edmonds-Karp (EK)** are max-flow algorithms, however they differ in runtime.

- **FF:** $O(mC)$
- **EK:** $O(nm^2)$

EK is a polynomial-time algorithm, but FF is not. Can we construct a graph where FF is slower EK?

## Negative Cycle Detection Algorithms
Both **Bellman-Ford (BF)** and **Floyd-Warshall (FW)** can detect negative cycles in a simple, directed, weighted graph. However, they go about this slightly differently, and with differing time complexities.

- **BF (one source):** $O(nm)$ - This only detects a negative cycle when the negative cycle is reachable from a single source node.
- **BF (all sources):** $O(n^2m)$ - This can detect a negative cycle anywhere in the graph, achieved by applying BF to all possible source nodes.
- **FW:** $O(n^3)$ - This can detect negative cycles anywhere in the graph. This algorithm is not designed to determine shortest paths from a single source node to all nodes reachable from that source.

The form of the question and the topology of the graph will determine which of these 3 algorithms will perform the best for a given question.

## Reachability Analysis
The following algorithms are listed as being useful for "Reachability Analysis" in the [[04.0.1 - Graphs - Black Box Algorithms]] notes.

- **DFS:** $O(n+m)$
- **BFS:** $O(n+m)$
- **Dijkstra's:** $O((n+m) log \space n)$
- **Bellman-Ford (BF) (one source):** $O(nm)$
- **Bellman-Ford (BF) (all sources):** $O(n^2m)$
- **Floyd-Warshall (FW):** $O(n^3)$

**DFS** and **BFS** have the same time complexity, though **BFS** is generally known for having a higher space complexity compared to **DFS**. BFS needs to keep track of a frontier of nodes which have the same distance from the starting node, while DFS only needs to keep track of nodes which have not yet been explored, without any qualitative ordering to those nodes. The difference here may be useful depending on whether you need to answer 2 questions, or just one.

**Dijkstra's** algorithm is similar to BFS, but operates on a different question. **BFS** finds the minimum distance between a starting node and all reachable nodes, where distance is the number of edges. **Dijkstra** finds the minimum distance between a starting node and all reachable nodes, where distance is in terms of edge weights. This difference causes Dijkstra to require an extra multiplicative $log(n)$ time complexity over BFS. However, that doesn't mean that BFS can't be used for connectivity analysis on a weighted graph.

**BF** and **FW** produce essentially the same output as **Dijkstra**, except they can operate on graphs that have negative edges.

## Minimum Spanning Trees
Both **Prim's** and **Kruskal's** algorithm produce minimum spanning trees. Both algorithms accomplish this in $O(m \space log \space n)$ time. Their main difference is in their output format.

- **Prim's** outputs an adjacency table named `prev`, which links each nodes to the index of the prior node. The root node of the MST has a `prev[root]=nil`.
- **Kruskal's** outputs a list of `n-1` edges in an adjacency-list format.
