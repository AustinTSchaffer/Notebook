## Complexity Classes
- NP = the class of all **search** problems
	- can use **decision** problems
	- Forget about the notion of decision. Focus on search.
- P = the class of search problems that are solvable in polynomial time
- P is a subset of NP ($P \subset NP$)
- Rough definition of search problem
	- A problem where we can efficiently verify solutions
	- "efficiently" = verifiable in polynomial time
- What's all this $P=NP$ vs $P \ne NP$ business?
	- $P$ - solving a problem in polynomial time
	- $NP$ - verifying a solution in polynomial time
	- Are these the same set of problems?
	- Is the process of verifying a solution in polynomial time the same as the process of generating that solution in polynomial time?

## Search Problems
**Form:** Given instance $I$, find a solution $S$ for $I$ if one exists. Output NO if $I$ has no solutions.

**Requirement:** To be a search problem, if given an instance $I$ and solution $S$, then we can verity that $S$ is a solution to $I$ in polynomial time (wrt $|I|$).

We only have to verify solutions when we're given a solution.

## Satisfiability Problem (SAT)
- This is one of the original NP-complete problems
- **Input:** Boolean formula $f$ in CNF, with $n$ variables and $m$ clauses.
- **Output:** satisfying assignment if one exists, and NO (unsat.) otherwise.

Example:
- $f=(x_3 \vee \overline{x_2} \vee \overline{x_1}) \wedge (x_1) \wedge (x_2 \vee \overline{x_3}) \wedge (\overline{x_1} \vee \overline{x_3})$
- Clause 2 forces $x_1=T$
- Clause 4 forces $x_3=F$
- Clause 3 is redundant.
- Clause 1 forces $x_2=F$

Given $f$ and assignment of T/F to $x_1,x_2,...,x_n$, what is the running time to verify?
- There are $n$ variables.
- There are $m$ clauses.
- Each clause is made of some number of literals. This can be unbounded, based on the definitions provided in this lecture so far.
- For each of $m$ clauses, we need to iterate over the unique set of literals that comprise the clause and see if any of the literals are True. There are at most 2n unique literals in each clause.
- $O(nm)$
- Therefore SAT $\in NP$

## Colorings in NP
- The k-colorings problem
- **Input:**
	- undirected $G=(V,E)$
	- integer $k \gt 0$. $k$ is the number of colors.
- **Output:**
	- Assign each vertex a color in $\{1, 2, ..., k\}$
	- Adjacent vertices must have different colors.
	- Return NO if no such $k$-coloring exists for $G$.
- k-colorings is in NP.
	- For each vertex ($v \in V$)
		- check all neighboring vertices ($u \in V$)
		- If any have the same color as $v$, the k-coloring is incorrect.
	- Classic $O(n+m):n=|V|,m=|E|$ linear graph algorithm
	- The lectures state that this is $O(m)$ time, which makes sense. You don't need to check vertices which have no neighbors. This depends on your graph data structuring.

## MST
- **Input:** $G=(V,E)$ with positive edge lengths.
- **Output:** tree $T$ with minimum weight.
- This problem is in both $P$ and $NP$
	- MST $\in NP$ ?
		- Can we validate an MST in poly-time?
		- We can run BFS/DFS to check that $T$ is a tree that spans $G$
		- We can generate a new MST with a known correct algorithm (K's or P's) and compare the total weight against $T$.
		- $O(m \space log \space n) < O(mn) \le O(n^3)$
		- MST $\in NP$ ✅
	- MST $\in P$ ?
		- We first need to demonstrate that MST is a search problem. This was performed by validating that MST $\in NP$.
		- Running Kruskal's/Prim's: $O(m \space log \space n) < O(mn) \le O(n^3)$
		- This is polynomial time for generating a solution.
		- MST $\in P$ ✅

## Knapsack Problem
- [[02.1 - Dynamic Programming 2 - Knapsack]]
- **Input:**
	- $n$ objects
	- integer weights: $w_1,...,w_n$
	- integer values: $v_1,...,v_n$
	- capacity $B$
- **Output:**
	- subset $S$ of objects with total weight $\le B$ ($\sum_{i \in S} w_i \le B$)
	- maximum total value ($\max \{\sum_{i \in S}v_i\}$)
	- Variants allow or disallow repetition.
- Knapsack $\in NP$ ?
	- Given an instance $I=\{w_1, ..., w_n, v_1,...,v_n,B\}$
	- Given a solution $S$
	- We need to check solution $S$
	- Validate that $\sum_{i \in S} w_i \le B$. This is $O(n)$ time.
	- How do we validate that $S$ maximizes $\sum_{i \in S}v_i$?
	- This is the whole problem. We can't run the DP algorithm to validate, because the DP algorithm is exponential.
	- We currently are unable to prove (as a society) whether knapsack is **definitively in** NP or **definitively NOT in** NP.
	- "Knapsack is not known to be in NP."
- Knapsack $\in P$ ?
	- No, the best algorithms for generating an exact solution are $O(nB)$
	- $B$ is represented in $log(B)$ bits.
	- Therefore $O(nB)$ is **exponential** in the input size.

## Knapsack Search
- This is a variant of Knapsack which is in NP
- **Input:**
	- $n$ objects
	- integer weights: $w_1,...,w_n$
	- integer values: $v_1,...,v_n$
	- capacity $B$
	- **Plus a goal $g$**
- **Output:**
	- subset $S$ of objects with total weight $\le B$ ($\sum_{i \in S} w_i \le B$)
	- total value meets goal ($\sum_{i \in S}v_i \ge g$)
	- Variants allow or disallow repetition.
	- Returns NO if no such $S$ exists which meets the goal.
- Knapsack Search $\in NP$ ?
	- Given an instance $I=\{w_1, ..., w_n, v_1,...,v_n,B,g\}$
	- Given a solution $S$
		- We need to check solution $S$
		- We don't need to validate the "NO" result.
	- Validate that $\sum_{i \in S} w_i \le B$. This is $O(n)$ time.
	- Validate that $\sum_{i \in S}v_i \ge g$. This is also $O(n)$ time.
	- Knapsack Search $\in NP$ ? ✅
- Some additional notes on verification
	- The size of W is $\sum_{i=1}^n w_i$
	- The size of V is $\sum_{i=1}^n v_i$
	- The time required to compute $\sum_{i \in S} w_i \le B$ is at most $O(n \space log \space W)$
	- The time required to compute $\sum_{i \in S}v_i \ge g$ is at most $O(n \space log \space V)$
	- The $log$ terms are effectively showing the amount of time required to add all of the bits in all of the numbers.
	- These are still both polynomial in the input size, even for arbitrarily large integers.

## Terminology
- $P$ stands for "polynomial time"
- $NP$ stands for "nondeterministic polynomial time"
	- This the class of problems that can be solved in polynomial time on a **non-deterministic** machine.
	- These are machines that are allowed to guess at each step.
	- Simulated annealing.
	- There must exist a path in a random automata from a given input state to an optimal state.
- $P \text{ vs } NP$
	- $NP$ is the class of all search problems. Search problems must be verifiable in poly-time.
	- $P$ is the class of search problems (NP problems) that can further be **solved** in poly-time.
	- $P \subset NP$
	- Is there truly a separation? Are all problems in NP also in P?

- if $P \ne NP$, what are the intractable problems?
	- These are the $NP$-complete problems.
	- These are the hardest problems in the class NP
	- if $P \ne NP$, then all NP-complete problems are not in $P$.
	- There may be other problems in NP which are currently not in P, but are not classified as NP-complete. The NP-complete problems are just the problems which are **guaranteed** to be in NP if $P \ne NP$.
	- If there exists an NP-complete problem which can be solved in polynomial time, then $P=NP$.
	- One example is SAT. Theoretically we can reduce all search problems to SAT. Then if we later prove that SAT is in P, then all search problems are in P. Thereby P=NP.

## SAT is NP-Complete
- "SAT is NP-complete" means
	1. SAT $\in NP$. Refer to earlier for the proof that SAT $\in NP$
	2. SAT is the hardest problem in the class of NP problems.
		- What does this mean? It means that SAT is the "least likely" to have an "efficient" (poly time) solution.
		- If we can solve SAT in poly-time, then we can solve every problem in NP in poly-time.
		- For all of the problems in NP, there is a polynomial-time reduction to the SAT problem.
		- If then we have an efficient algorithm for SAT, then all NP problems can share that solution.
- if $P \ne NP$ then $SAT \notin P$.
- We can logically conclude that currently nobody knows whether $P=NP$ nor whether $SAT \in P$.
	- Prizes unclaimed.
	- Fields medals not-awarded

## Reductions
- Consider problems A and B
- Reducing A to B
- Example
	- A = Colorings
	- B = SAT
- Reduction symbolizing
	- $A \rightarrow B$ - "A can be reduced to B"
	- $A \le B$ - "A is at most B"
	- "B" is the "harder" problem.
	- A solution for A doesn't necessarily solve B.
- If we can solve problem B in poly-time, then we can use that algorithm to solve A in poly-time (as long as there exists a P-time algorithm to reduce A to B).

### How to do a reduction?
$Colorings \rightarrow SAT$
- Suppose that there is a poly-time algorithm alg for SAT, and we use it to get a poly-time alg. for colorings.
- Put the SAT algorithm in a black box. We don't care how it works, just the input/output/runtime spec.
	- Use some transformation $f$ to transform an instance of B into an instance of A.
	- This produces either some solution to A, or "NO"
		- We use another transformation $h$ to transform the solution to A into a solution for B.
		- If A had no solution, then B has no solution. We don't need to transform "NO".

![[Pasted image 20260324152336.png]]

- $I_B$ - instance of problem B.
- $I_A=f(I_B)$ - instance of problem A.
- $S_A=Alg_A(I_A)$ - Solution to problem A
- $S_B=h(S_A)$ - Solution to problem B
- $S_B=h(Alg_A(f(I_B)))$ - The full chain of events.
- If $S_A=NO$, then $h(S_A)=NO$

### More on Reductions
- We need to define $f$ and $h$
- $f:$ input for colorings $\rightarrow$ input for SAT
	- Input for colorings: $G,k$
	- Input for SAT: $f(G,k)$
- $h:$ solution for $f(G,k)$ $\rightarrow$ solution for colorings
	- Solution for SAT: $S$
	- Solution for Colorings: $h(S)$
- Need to prove
	- if $S$ is a solution to $f$, then $h(S)$ is a solution to the original input.
	- $S$ is a solution to $f(G,k)$ $\iff$ $h(S)$ is a solution to $I=(G,k)$

See [[06.1 - NP - Theory Guidance]] for more info on what's required here.

## NP-completeness Proof
- To show: Independent Sets (IS) problem is NP-complete
- We need to show:
	- $IS \in NP$. This is fairly straightforward in most cases.
	- For every problem $A \in NP$, we need to show $A \rightarrow IS$
		- How?
		- In practice, do we transform the SAT problem into $IS$?
- Suppose that we know SAT is NP-complete.
	- for all $A \in NP$, $A \rightarrow SAT$
	- Suppose we show $SAT \rightarrow IS$
	- If so, then for all $A \in NP$ there exists a double reduction $A \rightarrow SAT \rightarrow IS$
	- We can shorten this chain to $$\forall_{A \in NP} \space A \rightarrow IS$$
- For a given problem B that _might_ be NP-complete, we simply need to show that there exists an NP-complete problem that can be reduced to B. SAT is the common one since it's so flexible, but there may be a different NP-C problem which is easier to reduce.
